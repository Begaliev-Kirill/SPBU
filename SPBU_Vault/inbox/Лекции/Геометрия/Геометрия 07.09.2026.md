# Множества
Множество - неупорядоченная совокупность различимых элементов, выделенных по определенном признаку.\
$\gimel \{a,b\} \text{ - множество}, a = b \Leftrightarrow \{a,b\} = \{a\}$ - различимость элементов обязательна

### Обозначения  
$A,B,C,D \dots$ - Множества, $a,b,c,d \dots$ - элементы множества.\
$a \in A$ - элемент a принадлежит (лежит в) множеству(e) A, $a \notin A$ - не принадлежит (не лежит)\
$\varnothing$ - пустое множество, не содержит в себе ни одного элемента, $|\varnothing| = 0$\
$U$ - универсум, общее множество из элементов которого составляются все остальные множетсва при решении определенной задачи. Грубо говоря ограничивает рассматриваемую область при решении

#### Способы задать множество:
1. $\{a,b,c,d,\cdots\}$ - напрямую вписать элементы
2. $\{a \in \N : условие\}$ - через условие, например $\{a \in \N : a \ mod \ 3 = 0\} = \{3,6,9,\cdots\}$
3. $\{1,2,3,...,100\}$ - интуитивно
4. $C = A \cup B$ - через операции с другими множествами 

### Часто встречаемые множества
$$
\N \text{ - натуральные числа, } = \{1,2,3,\cdots\} \\
\Z \text{ - целые числа, } = \{0,-1,1,-2,2,\cdots\} \\
\Bbb{Q} \text{ - рациональные числа, } = \{\frac{n}{m}: n \in \Z, m \in \N\} \\
\R \text{ -вещественные числа, } = \{\lim{\{a_n\}_{n=1}^{\infty}} : a_n \in \Bbb{Q}, \forall \epsilon \in \Bbb{Q}_{>0} \ \exists \ N \in \N : \forall n,m > N |a_n - a_m| < \epsilon\} \\
\Bbb{I} \text{ - Иррациональные числа, } = \{\Bbb{R} \setminus \Bbb{Q}\} \\
I\text{ (не путать с } \Bbb{I} \text{) } \text{ - множество индексов, } = \text{чаще всего } \N \text{(но не всегда)}\\
\Bbb{C} \text{ - комплексные числа, } = \{(a, b) = a + bi : a,b \in \R , i^2 = -1\} \\
$$

### Операции над множествами
1. $\cup$ - объединение, $X \cup Y = \{a: a \in X \ || \ a \in Y\}$
2. $\cap$ - пересечение, $X \cap Y = \{a: a \in X\ \& \ a \in Y\}$
3. $\setminus$ - разность, $X \setminus Y = \{a: a \in X \ \& \ a \notin Y \}$
4. $\overline{X}$ - дополнение, $\overline{X} = \{a \in U: a \notin X\}$
5. $\triangle$ - симметрическая разность, $X \triangle Y = \{A \setminus B\} \cup \{B \setminus A\}$

Операции объединения, пересечения и симметрической разности **коммутативны** и **ассоциативны**

#### Формулы Де-Моргана
$\overline{A \cup B} = \overline{A} \ \cap \ \overline{B}$, общий случай $\overline{\displaystyle\bigcup_{i \in I} A_i} = \displaystyle\bigcap_{i \in I} \overline{A_i}$ \
$\overline{A \cap B} = \overline{A} \ \cup\ \overline{B}$, общий случай $\overline{\displaystyle\bigcap_{i \in I} A_i} = \displaystyle\bigcup_{i \in I} \overline{A_i}$

### Декартово произведение
$A \times B = \{(a,b) : a \in A, b \in B\}$ - декартово произведение, набор всевозможных упорядоченных кортежей (чаще всего будет рассматриваться частный случай в виде пар).
>[!info] Кортеж
>Кортеж из n элементов - упорядоченный набор элементов $(a_1, a_2, a_3, \cdots)$
>$(a,b) \neq (b,a)$ - порядок важен

# Подмножества
$X \subset Y \Leftrightarrow (\forall x \in X : x \in Y)$ - 
Мн-во X называется подмножеством Y, если все элементы из X лежат в Y

### Обозначения
1. $A \subset B$ - A является подмножеством B
2. $A \subsetneqq B$ - А является собственным подмножеством B, $\exists \ x \in B : x \notin A$
3. Некоторые преподы любят делать $\subset$ собственным подмножеством, а с помощью символа $\subseteq$ показывать что подмножество не обязательно собственное,по усмотрению лектора
4. $A \supset B$ - B содержит А (B является надмножеством А)

### Важные свойства
1. $\forall A \text{ - множество } \Rightarrow \varnothing \subset A$
2. $\varnothing \subset \varnothing$
3. $A = B \Leftrightarrow A\subset B \ \& \ B \subset A$
4. $\forall A,B \text{ - множества }, A \subset B \Rightarrow |A| \leq |B|$

### Множество всех подмножеств
$\gimel A$ - множество, множество его подмножеств записывается как $2^A$ потому что имеет мощность $2^{|A|}$(Доказательства не было).
$$
2^A = \{B : B \subset A\} \\
\gimel A = \{1,2,3\} \Rightarrow 2^A = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}
$$

### Определение и обозначения
$\gimel A, B \text{ - множества }, \Gamma \subset A \times B$ \
$\cal C := (A,B, \Gamma)$ - соответствие, $a \cal C b \Leftrightarrow (a,b) \in \Gamma$, $a \cal C b$ - а в отношении с b\

Соответствие $f = (A,B,R)$ называется отображением, если выполняется \
$\forall a \in A \ \forall b,c \in B \ afb, afc \Rightarrow b=c$, или же \
$\forall a \in A \ \exists!\ b \in B : afb$

Обозначают $f : A \rightarrow B$, тогда $A$ - область определения, $B$ - область значений, $R$ - график отображения \
Отдельно отображаемый элемент записывают как $f(a) = b$, Иногда для удобства пишут\
$f(A) = B_0$, подразумевая, что мы отображаем каждый элемент множества $A$ в область значений $B$. \
$A$ - прообраз $B_0$, или $\{a \in A : \exists \ b \in B_0 : f(a) = b\}$ \
$B_0$ - образ $A$, или $\{b \in B : \exists \ a \in A : f(a) = b\}$

# Векторные пространства
$V$ - множество, $K$ - поле (чаще всего $\R$ или $\Complex$)
$+ : V \times V \rightarrow V : (u,v) \rightarrow u + v$ - операция "Сложение"
$\bullet : K \times V \rightarrow V : (\lambda,v) \rightarrow \lambda v$ - операция "Умножение на скаляр"

Упорядоченная четверка $(V, K, +, \bullet)$ называется векторным пространством, если выполнены следующие аксиомы:
1. $\forall u,v \in V \ u+v = v + u$ - коммутативность сложение
2. $\forall u,v,w \in V \ (u+v) + w = u +(v + w)$ - ассоциативность сложения
3. $\exists \ \overline{0} \in V : \forall u \in V \ u + \overline{0} = u$ (в дальнейшем $\overline{0}$ могут использовать просто как 0, надо следить за контекстом и не путать со скаляром) - существование нейтрального по сложению элемента
4. $\forall u \in V \ \exists \ (-u) \in V : u + (-u) = \overline{0}$ - существование обратного элемента
5. $\forall \lambda, \mu \in K\ \forall u \in V \ (\lambda + \mu)u = \lambda u + \mu u$ - дистрибутивность скалярного умножения относительно сложения векторов
6. $\forall \lambda \in K \ \forall u,v \in V \lambda (u+v) = \lambda u + \lambda v$ - дистрибутивность скалярного умножения относительно сложения скаляров
7. $\exists \ 1 \in K : \forall u \in V \ 1 \cdot u = u$ - существование нейтрального по умножению скаляра
8. $\forall \lambda, \mu \in K \ \forall  u \in V \ (\lambda \mu) u = \lambda (\mu u)$ - ассоциативность умножения на скаляр

Оффтопом было сказано, что свойства (1-4) образуют аксиомы Абелевой(коммутативной) группы по сложению
