# Множества
Множество - неупорядоченная совокупность различимых элементов, выделенных по определенном признаку.\
$\gimel \{a,b\} \text{ - множество}, a = b \Leftrightarrow \{a,b\} = \{a\}$ - различимость элементов обязательна

### Обозначения  
$A,B,C,D \dots$ - Множества, $a,b,c,d \dots$ - элементы множества.\
$a \in A$ - элемент a принадлежит (лежит в) множеству(e) A, $a \notin A$ - не принадлежит (не лежит)\
$\varnothing$ - пустое множество, не содержит в себе ни одного элемента, $|\varnothing| = 0$\
$U$ - универсум, общее множество из элементов которого составляются все остальные множетсва при решении определенной задачи. Грубо говоря ограничивает рассматриваемую область при решении

#### Способы задать множество:
1. $\{a,b,c,d,\cdots\}$ - напрямую вписать элементы
2. $\{a \in \N : условие\}$ - через условие, например $\{a \in \N : a \ mod \ 3 = 0\} = \{3,6,9,\cdots\}$
3. $\{1,2,3,...,100\}$ - интуитивно
4. $C = A \cup B$ - через операции с другими множествами 

### Часто встречаемые множества
$$
\N \text{ - натуральные числа, } = \{1,2,3,\cdots\} \\
\Z \text{ - целые числа, } = \{0,-1,1,-2,2,\cdots\} \\
\Bbb{Q} \text{ - рациональные числа, } = \{\frac{n}{m}: n \in \Z, m \in \N\} \\
\R \text{ -вещественные числа, } = \{\lim{\{a_n\}_{n=1}^{\infty}} : a_n \in \Bbb{Q}, \forall \epsilon \in \Bbb{Q}_{>0} \ \exists \ N \in \N : \forall n,m > N |a_n - a_m| < \epsilon\} \\
\Bbb{I} \text{ - Иррациональные числа, } = \{\Bbb{R} \setminus \Bbb{Q}\} \\
I\text{ (не путать с } \Bbb{I} \text{) } \text{ - множество индексов, } = \text{чаще всего } \N \text{(но не всегда)}\\
\Bbb{C} \text{ - комплексные числа, } = \{(a, b) = a + bi : a,b \in \R , i^2 = -1\} \\
$$

### Операции над множествами
1. $\cup$ - объединение, $X \cup Y = \{a: a \in X \ || \ a \in Y\}$
2. $\cap$ - пересечение, $X \cap Y = \{a: a \in X\ \& \ a \in Y\}$
3. $\setminus$ - разность, $X \setminus Y = \{a: a \in X \ \& \ a \notin Y \}$
4. $\overline{X}$ - дополнение, $\overline{X} = \{a \in U: a \notin X\}$
5. $\triangle$ - симметрическая разность, $X \triangle Y = \{A \setminus B\} \cup \{B \setminus A\}$

Операции объединения, пересечения и симметрической разности **коммутативны** и **ассоциативны**

#### Формулы Де-Моргана
$\overline{A \cup B} = \overline{A} \ \cap \ \overline{B}$, общий случай $\overline{\displaystyle\bigcup_{i \in I} A_i} = \displaystyle\bigcap_{i \in I} \overline{A_i}$ \
$\overline{A \cap B} = \overline{A} \ \cup\ \overline{B}$, общий случай $\overline{\displaystyle\bigcap_{i \in I} A_i} = \displaystyle\bigcup_{i \in I} \overline{A_i}$
# Отношения
### Определение и обозначения
$\gimel A, B \text{ - множества }, R \subset A \times B$\
$\rho:= (A,B, \Gamma)$ - соответствие, $a \rho b \Leftrightarrow (a,b) \in R$, $a \rho b$ - а в отношении с b\

### Свойства бинарных отношений
1. Рефлексивность $\Leftrightarrow \forall a \in A \ a \rho a$
2. Симметричность $\Leftrightarrow \forall a,b \in A  \ a\rho b \Rightarrow b \rho a$
3. Транзитивность $\Leftrightarrow \forall a,b,c \in A \ a\rho b, b\rho c \Rightarrow a\rho c$

### Отношение эквивалентности
Бинарное отношение называется эквивалентным, если оно (1-3) рефлексивно, симметрично и транзитивно. Обозначается символом $\sim$\
$\widetilde{x} = \{a \in A : a \sim x \}$ - класс эквивалентности элемента x, по рефлексивности $\forall x \in A\ x \in \widetilde{x}$\
$\gimel \ a_0 \in \widetilde{a} \Rightarrow a_0 \sim a.\ \gimel\ x \in \widetilde{a} \Rightarrow x \sim a \Rightarrow x \sim a_0$ по транзитивности тогда $x\in \widetilde{a_0} \Rightarrow \text{т.к. верно } \forall x \in \widetilde{a} \text{ , то } \widetilde{a_0} \subset \widetilde{a}$ \
В обратную сторону таким же образом можем доказать что $\widetilde{a} \subset \widetilde{a_0}$, из чего можем сделать вывод, что $\widetilde{a_0} = \widetilde{a}$\
Рассмотрим случайный $x \in A$, тогда возможно два случая:
1. $x \sim a \Rightarrow \widetilde{x} = \widetilde{a}$
2. $x \nsim a. \ \forall  x_0 \in \widetilde{x}: x_0 \sim x \Rightarrow x_0 \nsim a \Rightarrow x_0 \notin \widetilde{a} \Rightarrow \widetilde{x} \cap \widetilde{a} = \varnothing$

Т.к. $\forall a \in A : a \in \widetilde{a}$, то $A = \displaystyle\bigcup_{i \in I} \widetilde{a_i}$, учитывая два случая, можем сделать вывод, что множество $A$ можно разбить на непересекающиеся классы эквивалентности\
$A/\sim$ - разбиение $A$ на классы эквивалентности(фактор множество),\
$A/ \sim \ = \{\widetilde{a_i} : a_i \in A, a_i \neq a_j \ \forall i,j \in I, i \neq j\}$ \
А так же $a \sim b \Leftrightarrow \exists \ i \in I : a_i \in A,  a \in \widetilde{a_i}, b \in \widetilde{a_i}$
# Отображение
Отношение $f = (A,B,R)$ называется отображением, если выполняется \
$\forall a \in A \ \forall b,c \in B \ afb, afc \Rightarrow b=c$, или же\
$\forall a \in A \ \exists!\ b \in B : afb$

Обозначают $f : A \rightarrow B$, тогда $A$ - область определения, $B$ - область значений, $R$ - график отображения \
Отдельно отображаемый элемент записывают как $f(a) = b$, Иногда для удобства пишут\
$f(A) = B_0$, подразумевая, что мы отображаем каждый элемент множества $A$ в область значений $B$. \
$A$ - прообраз $B_0$, или $\{a \in A : \exists \ b \in B_0 : f(a) = b\}$ \
$B_0$ - образ $A$, или $\{b \in B : \exists \ a \in A : f(a) = b\}$

## Свойства отображений
1. Инъекция - отображение инъективно, если $\forall x_1, x_2 \in X, x_1 \neq x_2 : f(x_1) \neq f(x_2)$
2. Сюръекция - отображение сюръективно, если $\forall y \in Y \ \exists \ x \in X : f(x) \in Y$
3. Биекция - отображение биективно, если оно инъективно и сюръективно. Так же называется взаимооднозначным соответствием. Можно задать условие кванторами:
$$ \forall y \in Y \ \exists ! \ x \in X : f(x) \in Y $$

$$

### Композиция отображений
$g : A \rightarrow B, f : B \rightarrow C$\
$f \circ g$ - композиция отображений, $\forall x \in A (f \circ g)(x) = f(g(x))$\
Композиция ассоциативна(доказательство ниже), но не коммутативна (очевидно)\
Док-во:\
$\gimel h : A \rightarrow B , g : B \rightarrow C, f : C \rightarrow D$ \
$((f \circ g) \circ h)(x) = (f \circ g)(h(x)) = f(g(h(x)))$\
$(f \circ(g \circ h))(x) = f ((g \circ h)(x)) = f(g(h(x)))$\
Так как при перестановке скобок ничего не поменялось, то ассоциативность доказана $\blacksquare$ 

### Сужение отображения
$\gimel f : A \rightarrow B, Im(f) \subset B', A' \subset A, B' \subset B$\
Введем понятие сужения: $f|_{A'} : A' \rightarrow B$ так, что $\forall a' \in A' \ f|_{A'} (a') = f(a')$\
Тогда, т.к. $A' \subset A$ и $Im(f) \subset B' \subset B$, то $Im(f|_{A'}) \subset B'$ из чего можно сделать вывод, что сужение $f|_{A'}$ мы можем задать(сопоставить с) новым отображением $f' : A' \rightarrow B'$.\
Не знаю для чего нам этот вывод, но такое сопоставление может случайно добавить сужению сюръективность, возможно в этом ключевая задача.
