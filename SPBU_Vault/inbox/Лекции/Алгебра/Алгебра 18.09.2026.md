# Свойства делимости в кольце целых чисел.
### Определение
$\gimel a, b \in \Z$, говорят, что $a$ делится на $b$ ($a\  \vdots \ b$, $а$ кратно $b$), или что $b$ делит $a$ ($b \ | \ a$), если $\exists \ x \in \Z : a = bx$

Число $p \in \N$ называется простым, если $p \ \vdots \ 1, \ p \ \vdots \ p, \ \forall x \in \N \ p  \not{\vdots} \ x$\
(Нет делителей кроме 1 и самго себя)  

Говорят, что $a$ ассоциирован с $a'$, если $a \ | \ a'$ и $a' \ | \ a$, обозначают $a \sim a'$,\
неассоциированные элементы обозначают $a \not\sim a'$\
Ассоциированность, очевидно, бинарное отношение и задаётся на конкретном множестве

>[!info] Семейства
>Семейство - просто проиндексированное множество. В обычном множестве элементы с одинаковым значением считаются полностью одинаковыми и не дублируются, в семействах можно хранить что-то вроде $\{a_{1}, a_{2}, \dots\}$, где значения $a_1$ и $a_2$ будут равны, но элементы будут считаться различными из-за разных индексов. Обозначается $(a_i)_{i \in I}$ или просто $(a_i)$\
>Уже известное нам семейство - последовательность $\{x_n\}_{n \to \infty}^{\infty}$, элементы последовательности могут повторять одинаковое значение, но считаются различными\
    >Линейное представление (линейная комбинация) семейства - просто сумма всех элементов семейства, умноженных на какие-то коэффициенты (обычно раличные).\
> $\displaystyle\sum_{i \in I} a_i \cdot u_i$, $u_i$ - коэффициент при конкретном $a_i$ 

### Свойства делимости:
1. $\forall a \in Z \ \ \ 0 \ \vdots \ a$ - $0$ делится на любое число
2. $\forall a \in \Z \ \ \ 1 \ | \ a$ и $a \ | \ a$
3. $a \ | \ b, \ b \ | \ c \Rightarrow a \ | \ c$ - делимость транзитивна
4. $\forall a,b,c \in \Z \ \ \ c \ | \ a, \ c \ | \ b \Rightarrow c \ | \ a \pm b$, а также $\forall u,v \in Z \ c \ | \ a \cdot u \pm b \cdot v$
5. Если все члены семейства $(a_i)_{i \in I}$ делятся на $b$, то и любая линейная комбинация (любое линейное представление) будет делиться на $b$

## Теорема о делении целых числе с остатком
$\forall a,b \in \Z, b \neq 0 \ \ \exists! \ q, r \in Z : \ \ a = q \cdot b + r, \ \ 0 \leq r < |b|$\
Надо доказать существование $(\exists)$ и единственность $(!)$

Доказательство:\
$(\exists)$ Рассмотрим 3 случая:\
$(I)$ $\gimel a \geq 0, b > 0$, зафиксируем *любое* $b$. Доказывать будем по индукции\
База индукции: $\gimel a < b$, тогда, очевидно, $a = b \cdot 0 + a, \ 0 \leq a < b$, пара значений\
$q = 0, r = a$ удовлетворяет условиям теоремы.\
Индукционный переход: предположим, что $\forall k \in \Z, k < a$ теорема верна. Если из этого следует, что $\forall a \geq b$ теорема верна, то по индукции случай будет доказан.\
$a \geq b \Rightarrow 0 \leq a - b < a$ ($a - b < a$ т.к. $b > 0$), $a - b < a \Rightarrow$ по предположению индукции для\
$a - b$ теорема верна $\Rightarrow \ \exists \ q', r' \in \Z \  : a-b = q' \cdot b + r' \Rightarrow a = (q' + 1) \cdot b + r'$\
Получаем, что пара значений $q = q' + 1, r = r'$ удовлетворяет условиям теоремы,\
случай $(I)$ доказан

$(II)$ $\gimel a < 0, b > 0$, зафиксируем любое $b$,\
Тогда $-a > 0$ и по случаю $(I)$ получаем, что $\exists \ q', r' : -a = b \cdot q' + r'$, $0 \leq r' < b$\
Если $r' = 0$, то $-a = b \cdot q' \Rightarrow a = b \cdot (-q') \Rightarrow$ пара значений $q = -q', r = 0$ удовлетворяет условиям теоремы\
Если $r' > 0$, то $-a = b \cdot q' + r' \Rightarrow a = b \cdot (-q') + (-r') \Rightarrow a = b \cdot (-q') - b + b + (- r')$\
В итоге $a = b \cdot (-q'-1) + (b-r') \Rightarrow$ пара значений $q = -q' -1, \ r = b-r'$ удовлетворяет условиям теоремы
случай $(II)$ доказан

$(III)$ $\gimel b < 0$, зафиксируем произвольное $a$\
$-b > 0 \Rightarrow$ из случаев $(I), (II)$ получаем, что $\exists \ q', r' \in \Z : a = (-b) \cdot q' + r'$\
Тогда $a = b \cdot (-q') + r'$, при этом $0 \leq r' < b = |-b|$\
Получаем, что пара значений $q = -q', r = r'$ удовлетворяет условиям теоремы,\
случай $(III)$ доказан

(!) $\gimel a = b \cdot q_1 + r_1 = b \cdot q_2 + r_2$, тогда $0 \leq r_1 \leq r_2 < |b|$ (порядок $r_1, r_2$ не важен т.к. доказываем единственность)\
Тогда $0 \leq r_2 - r_1 < |b|$, и из $b \cdot q_1 + r_1 = b \cdot q_2 + r_2$ получаем $b \cdot (q_1 - q_2) = r_2 - r_1$,\
Откуда следует, что $|b|\cdot |q_1 - q_2| = |r_2 - r_1| < |b|$, что в $\Z$ возможно только при $q_1 = q_2$,
$0 = |r_2 - r_1| \Rightarrow r_2 = r_1 \Rightarrow$ набор значений $q, r$ единственнен $\blacksquare$
# Наибольший общий делитель
### Определение
$\gimel \ (a,b)$ - пара чисел, $a, b \in \Z$\
Наибольшим общем делителем этой пары чисел (в дальнейшем $НОД(a, b)$) называется $d \in \Z$, такое что $d \ | \ a, \ d \ | \ b,  \ \ \forall x \in \Z \ \ \  x \ | \ a, \ x \ | \ b \ \Rightarrow \ x \ | \ d$\

Аналогично, для семейства $(a_i)_{i \in I}$ $НОД(a_i)$ будет $d \in \Z : \forall i \in I \ \ d \ | \ a_i$,\
$\forall x \in \Z$ если $\forall i \in I \ \ x \ | \ a_i$, то $x \ | \ d$

Пара чисел называется **взаимно простой** (я буду обозначать $a \perp b$, но препод пишет словами обычно), если $НОД(a,b) = 1$

### Свойства НОД
1. $НОД(ca,cb) = c \cdot НОД(a,b)$
2. $a \perp b \Rightarrow НОД(a,c) \cdot НОД(b,c) = НОД(a \cdot b, c)$
3. $НОД(a, 0) = a$, $НОД(a,1) = 1$
4. $b \ | \ a \Rightarrow НОД(a, b) = b$
5. $a \perp c \Rightarrow НОД(ab,c) = НОД(b,c)$
6. $\forall a,b,c \in \Z \ \ НОД(a,b) = НОД(a + bc, b)$
Небольшое доказательство свойства 6 (Лемма)\
$\gimel \ M$ - множество общих делителей $a,b$, $M'$ - множество общих делителей $a + bc, b$\
Тогда $x \in M \Leftrightarrow (x \ | \ a, \ x \ | \ b) \Leftrightarrow (x \ | \ a + bc, \ x \ | \ b) \Leftrightarrow x \in M' \ \ \blacksquare$\
Пользуемся очевидным свойством: $x \ | \ a, \ x \ | \ b$, значит $x \ | \ a + b$, $x \ | \ a + 2b$ $\dots \ x \ | \ a + bc$

### Два наибольших общих делителя
Предложение: $\gimel d - НОД(a,b)$ (или $НОД(a_i)$), тогда $d' - НОД(a,b)$ (или $НОД(a_i)$) $\Leftrightarrow$\
$\Leftrightarrow$ $d \sim d'$ (ассоциированы)\
Доказать надо в обе стороны

Доказательство: ($\Rightarrow$) $d, d' - НОД(a,b)$ (или $НОД(a_i)$) $\Rightarrow d \ | \ d', \ d' \ | \ d$\
Тогда по определению $\sim$ получаем $d \sim d'$

($\Leftarrow$) $\gimel \ d \sim d'$\
$d \ \vdots \ d' \Rightarrow d'$ - общий делитель пары (или семейства)\
$d' \ \vdots \ d \Rightarrow d'$ делится и на все другие общие делители (т.к. $d$ делится на них)\
Из двух утверждений получаем, что $d'$ - наибольший общий делитель пары (или семейства) $\blacksquare$

Данным предложением бы доказали, что любой $d' \sim d$ тоже является НОД.\
В частности, $-d \sim d$, из чего получаем, что если $d \neq 0$, то имеем 2 $НОД$ для любой пары (или семейства). В случае с $d = 0$ $НОД$ один и равен $0$. Менять обозначений не будем, под $НОД(a,b)$ (или $НОД(a_i)$) будем иметь любой из двух наибольших общих делителей.

# Теорема о линейном представлении НОД
Утверждение: $\forall$ семейства $(a_i)_{i \in I}$ в $\Z$ $\exists \ НОД(a_i) = d$, тогда в $\Z$ $\exists (u_i)_{i \in I}$ такое,\
что $d = \displaystyle\sum_{i \in I} a_i \cdot u_i, \forall i \in I \ u_i \in \Z$
(Эта теорема показывает, что у **любой** комбинации целых чисел есть НОД, в том числе если числа повторяются, поэтому мы рассматриваем семейства, а не множества.\
Построить линейную комбинацию с коэффициентами $u_i$ можно с помощью обратного алгоритма Евклида, что должно было появляться на практике)

Доказательство:\
Если $\forall i \in I \ a_i = 0$, то $d = 0$, случай очевидный, можем зафиксировать $\forall i \in I \ u_i = 0$\
$\gimel$ в $(a_i)$ есть ненулевые члены\
$\gimel M = \{\displaystyle\sum_{i \in I} a_i \cdot y_i : \forall i \in I \ y_i \in \Z$ и почти все $y_i = 0$} - множество линейных комбинаций (сумм) семейства\
(почти все $y_i = 0$ нужно, чтобы даже для бесконечного числа $a_i$ линейная комбинация в $M$ была конечной)\
Очевидно, что $\forall j \in I \ a_j \in M$, т.к. можем взять $y_j = 1, \forall i \in I, i \neq j \ y_i = 0$, тогда, в частности, $M \neq \{0\}$

Множество $\{|x| : x \in M \setminus \{0\}\}$, очевидно, не пусто, состоит из положительных целых чисел и ограничено снизу, поэтому в нем есть $min = |d'| : d' \in M, \ d' \neq 0, \ d' = \displaystyle\sum_{i \in I} a_i \cdot u'_i$

Докажем, что $d'$ - $НОД(a_i)$\
Зафиксируем произвольный $j \in I$ и разделим $a_j$ на $d'$\
$a_j = d' \cdot q + r$, $0 \leq r < d'$ тогда $r = a_j - d' \cdot q = a_j - q \cdot \displaystyle\sum_{i \in I} a_i \cdot u'_i$, вынесем $a_j \cdot u_j$ из суммы\
$a_j - q \cdot \displaystyle\sum_{i \in I} a_i \cdot u'_i =$ $a_j - a_j \cdot u'_j \cdot q - q \cdot \displaystyle\sum_{i \in I, i \neq j} a_i \cdot u'_i =$ $a_j \cdot (1 - q \cdot u'_j) - q \cdot \displaystyle\sum_{i \in I, i \neq j}a_i \cdot u'_i$\
Занесем (-q) под сумму\
$a_j \cdot (1 - q \cdot u'_j) - q \cdot \displaystyle\sum_{i \in I, i \neq j}a_i \cdot u'_i =$ $a_j \cdot (1 - q \cdot u'_j) + \displaystyle\sum_{i \in I, i \neq j} -q \cdot a_i \cdot u'_i = r$\
Можем заметить, что $r$ является линейной комбинацией семейства $(a_i)$\
$r = 0$ или $|r| < |d'|$, но $d'$ - минимальное из $M$ (ненулевых линейных комбинаций), тогда неравенство $|r| < |d'|$ невозможно $\Rightarrow r = 0$, тогда получается, что $d' \ | \ a_j$\
Т.к. $j \in I$ был выбран произвольно, то $\forall i \in I \ \ d' \ | \ a_i$, тогда $d'$ - общий делитель $(a_i)$

Возьмем произвольный общий делитель $z$, т.к. $d' = \displaystyle\sum_{i \in I} a_i \cdot u'_i$, то $z \ | \ d'$, тогда получаем,\
что $d'$ делится на любой общий делитель и сам является общим делителем $\Rightarrow d'$ - $НОД(a_i)$

Если $d$ является $НОД(a_i)$, то $d \sim d'$ и $d' \ | \ d \Rightarrow d = \nu \cdot d', \nu \in \{-1, 1\}$\
($\nu$ это "ню", формально мы определяем $d$ как положительный $НОД$ в зависимости от знака $d'$)\
$d = \nu \cdot \displaystyle\sum_{i \in I}a_i \cdot u'_i = \displaystyle\sum_{i \in I}\nu \cdot a_i \cdot u'_i = \displaystyle\sum_{i \in I} a_i \cdot u_i$, где $u_i = \nu \cdot u'_i$ $\ \ \blacksquare$

# Алгоритм Евклида
Алгоритм Евклида полностью построен на свойстве номер (6) НОДа, свойство будет использоваться как Лемма 

$\gimel (a,b) : a,b \in \Z, \ \ b = 0 \Rightarrow НОД(a,b) = a$\
$\gimel \ b \neq 0$, по теореме о делении целых чисел с остатком $a = b \cdot q_1 + r_1, 0 \leq r_1 < |b|$\
По лемме $НОД(a,b) = НОД(b\cdot q_1 + r_1, b) = НОД(r_1, b)$\
Это и есть один шаг алгоритма, выражая далее одно значение из пары через другое мы получим строго убывающую последовательность $|b| \geq r_1 \geq r_2 \geq \dots \geq 0$\
Такая последовательность, очевидно, конечна и ограничена снизу.\
Следующий шаг не будет возможен, если $r_{k+1} = 0$, то есть мы применяем алгоритм до тех пор, пока не получим пару значений $НОД(r_k, 0) = r_k$\
Выходит, что $НОД(a,b) = r_k$ (Если $r_1 = 0$, то $a \ \vdots \ b \Rightarrow НОД(a,b) = b$)

Схема для лучшего понимания алгоритма:\
$a = b \cdot q_1 + r_1$\
$b = r_1 \cdot q_2 + r_2$\
$r_1 = r_2 \cdot q_3 + r_3$\
$\dots$
$r_{k-2} = r_{k-1} \cdot q_{k} + r_k$\
$r_{k-1} = r_k \cdot q_{k+1} + 0$ (на этом шаге $r_{k+1} = 0$)

# Понятие Кольца
### Аксиоматика
$(A, +, \bullet)$ - кольцо(часто $R$ от $ring$) на множестве $A$\
Аксиомы кольца:
1. $\forall a, b \in A \ a + b = b + a$ - коммутативность сложения
2. $\forall a,b,c \in A \ (a+b)+c = a + (b + c)$ - ассоциативность сложения
3. $\exists 0 \in A : \forall a \in A \ a + 0 = a$ - существование нейтрального по сложению элемента
4. $\forall a \in A \ \exists! \ -a \in A : a + (-a) = 0$ - существование противоположного элемента
5. $\forall a,b,c \in A \ (a \cdot b) \cdot c = a \cdot (b \cdot c)$ - ассоциативность умножения
6. $\forall a,b,c \in A \ a \cdot (b + c) = ab + ac$ - дистрибутивность умножения относительно сложения

Это были основные аксиомы, но часто кольца могут удовлетворять и другим:
1. $\forall a, b \in A \ a \cdot b = b \cdot a$ - коммутативность умножения (тогда кольцо будет называться коммутативным)
2. $\exists \ 1 \in A : \forall a \in A \ 1 \cdot a = a$ - существование нейтрального по умножению элемента (тогда кольцо будет называться кольцом с единицей)
3. $\forall a \in A, a \neq 0 \ \exists ! \ a^{-1} \in A : a \cdot a^{-1} = 1$ (обычно идёт вместе с (1-2) и её добавление образует из кольца поле, но без коммутативности умножения структура будет называться телом)

Примеры колец: $\Z, \Bbb{Q}, \R, \Bbb{C}, 2 \Z$ (кольцо четных чисел), абсолютно любое поле также будет считаться кольцом.

### Делители нуля 
$a \in R$ называетя делителем нуля, если $\exists x \in R, x \neq 0 : x \cdot a = 0$\
Кольцо $R$ называется **кольцом без делителей нуля**, если в нем не существует делителей нуля кроме самого $0$\
*Коммутативное* кольцо *с единицей* называется областью целостности, если это кольцо без делителей нуля
# Сравнимость
### Определение
$\gimel \ a, a', m \in \Z$, говорят, что $a$ сравнимо с $a'$ по модулю $m$, если $a-a' \ \vdots \ m$,\
обозначают $a \equiv a' (mod \ m)$, если $m$ фиксирован, то можно просто $a \equiv a'$\
Данное определение задаёт на множестве $\Z$ бинарную операцию сравнения
### Свойства сравнения
1. $\forall a \in \Z \ a \equiv a$ - рефлексивность (очевидно)
2. $\forall a,b \in \Z \ a \equiv b \Rightarrow b \equiv a$ - симметричность (очевидно)
3. $\forall a,b,z \in \Z \ a \equiv b, \ b \equiv c \Rightarrow a \equiv c$ - транзитивность
Небольшое доказательство транзитивности:\
$\begin{rcases} a \equiv b \Rightarrow a - b \ \vdots \ m\\ b \equiv c \Rightarrow b - c \ \vdots \ m \end{rcases}$ $\Rightarrow (a-c) = (a - b) + (b - c) \ \vdots \ m \Rightarrow a \equiv c$
4. $a \equiv a', b \equiv b' \Rightarrow a \pm b \equiv a' \pm b'$, $a \cdot b \equiv a' \cdot b'$\
Доказательство:\
$\begin{rcases} a \equiv a' \Rightarrow a - a' \ \vdots \ m \Rightarrow a - a' = m \cdot x \\ b \equiv b' \Rightarrow b - b' \ \vdots \ m \Rightarrow b - b' = m \cdot y\end{rcases}$ (1)\
(1) $\Rightarrow (a \pm a') - (b \pm b') = (a - a') \mp (b - b') = mx \mp my = m \cdot (x \mp y) \Rightarrow a \pm b \equiv a' \pm b'$\
(1) $\Rightarrow ab - a'b' = ab - a'b + a'b - a'b' = b \cdot (a - a') + a' \cdot (b - b')$\
$= b \cdot mx + a' \cdot my = m \cdot(bx + a'y) \Rightarrow ab \equiv a'b' \ \ \blacksquare$ 

5. $ac \equiv bc (mod \ m) \Rightarrow a \equiv b (mod \ m / НОД(c, m))$\
Доказательство: $\gimel \ d = НОД(m,c)$, тогда $c = d \cdot c_1, \ m = d \cdot m_1$, $c_1$ и $m_1$ взаимно простыы\
$ac \equiv bc (mod \ m) \Rightarrow ac - bc \ \vdots \ m \Rightarrow (a-b) \cdot c \ \vdots \ m \Rightarrow (a-b) \cdot d \cdot c_1 \ \vdots \ dm_1$\
$\Rightarrow (a-b) \cdot d \cdot c_1 = d \cdot m_1 \cdot x \Rightarrow$ $(a-b) \cdot c_1 = m_1 \cdot x$,\
 т.к. $c_1 \perp m_1$, то $(a - b) \ \vdots \ m_1 = m / d = m / НОД(m,c) \ \blacksquare$

Свойства 1-3 показывают, что $\equiv$ является отношением эквивалентности, а значит разбивает $\Z$ на классы эквивалентности. Такие классы в $\Z$ называются классами вычетов по модулю $m$, при фиксированном $m$ обозначаются $\overline{a}$\
$\overline{a}$ - класс вычета, порожденный числом $a$\
$a \equiv a' \Leftrightarrow \overline{a} = \overline{a'}$\
Множество представителей, выбранных по одному из каждого классов вычетов, называют **полной системой вычетов**

Свойство 4 показывает, что сравнение согласовано с операциями сложения и умножения, то есть являеться *конгруэнцией* в кольце $\Z$\
Это позволяет перенести операции кольца на множество классов конгруэнции, то есть на множество классов вычетов\
Операции определяются равенствами:\
$\overline{a} + \overline{b} = \overline{a + b}$\
$\overline{a} \cdot \overline{b} = \overline{ab}$\
Проверим, что класс-результат не зависит от выбора представителей классов-операндов:\
$\gimel \ \overline{a} = \overline{a'}, \overline{b} = \overline{b'}$, то есть $a'$ представитель класса $\overline{a}$ и $b'$ представитель класса $\overline{b}$\
$\begin{rcases} \overline{a} = \overline{a'} \Rightarrow a \equiv a' \\ \overline{b} = \overline{b'} \equiv b \equiv b' \end{rcases}$ $\Rightarrow$ $\begin{cases} a + b \equiv a' + b' \Rightarrow \overline{a+b} = \overline{a' + b'} \\ ab \equiv a'b' \Rightarrow \overline{ab} = \overline{a'b'} \end{cases}$\
В общем, благодаря свойству (4) все доказывается в одну строчку $\blacksquare$

Введенные операции задают на множестве классов вычетов структуру коммутативного кольца с единицей, такое кольцо называют **кольцом классов вычетов** по модулю $m$, обозначается как $\Z_{m}$\
Выполнение аксиом очевидно, $\overline{0}$ - нуль в сложении классов, $\overline{-a} = -\overline{a}$, $\overline{1}$ - единица в умножении классов

### Малая теорема Ферма
$p \in \N$ - просто, $\overline{a} \in \Z_p, \ \overline{a} \neq \overline{0} \Rightarrow \overline{a}^{\ p-1} = \overline{1}$\
$p \in \N$ просто и $a \in \Z \ \not\vdots \ p, \ a \neq 0$, то $a^{p-1} \equiv 1 (mod \ p)$\
Доказательсто не приводилось.
# Кольца вычетов
Утверждение: $\gimel a, m \in \Z$\
(1) Если $a \perp m$, то $\overline{a}$ обратим в $\Z_m$\
(2) Если $a \not\perp m$, то $\overline{a}$ - делитель нуля в $\Z_m$

Доказательство:\
(1) $a \perp m \Rightarrow НОД(a,m) = 1$\
По теореме о линейном представлении $НОД$ $\Rightarrow \exists u, v \in \Z : ua + mv = 1$\
Из этого следует, что $\overline{u}\cdot \overline{a} + \overline{m} \cdot \overline{v} = \overline{1} \Rightarrow \overline{u} \cdot \overline{a} = \overline{1} \Rightarrow \overline{u} = \overline{a}^{\ -1}$\
(2) $a \not\perp m \Rightarrow НОД(a,m) = d \not\sim 1 \Rightarrow a = da_1,\ m = dm_1$, $a_1 \perp m_1$\
$m = dm_1 \Rightarrow m_1$ не делится на $m \Rightarrow m_1$ не делитель нуля, но\
$\overline{a} \cdot \overline{m_1} = \overline{a \cdot m_1} = \overline{da_1m_1} = \overline{a_1dm_1} = \overline{a_1m} = \overline{a_1}\cdot \overline{m} = \overline{0} \Rightarrow \overline{a}$ - делитель нуля в $\Z_m \ \ \blacksquare$

### Следствие
(1) $p \in \N$, $p$ - простое $\Rightarrow \Z_p$ - поле\
(2) $m \in \N$, $m$ не простое и $m \neq 1 \Rightarrow \Z_m$ содержит ненулевые делители нуля.

Доказательство:\
(1) $\forall a \in \Z \ \ p \ | \ a \ \vee \ a \perp p \Rightarrow \overline{a} = \overline{0} \ \vee \ \overline{a}$ - обратимый, т.к. каждый ненулевой класс из $\Z_p$ обратим, то это добавляет к коммутативному кольцу с единицой $\Z_p$ аксиому обратимости, все 9 аксиом вместе соответствуют аксиомам поля.
(2) $m \neq 1$, $m$ не простой $\Rightarrow \exists$ нетривиальный делитель $a : a \ | \ m \Rightarrow НОД(m,a) = a \not\sim 1$, тогда $\overline{a}$ делит $\overline{m}$, при этом $m = xa \Rightarrow$ $a$ не делится на $m \Rightarrow a \not\sim m \Rightarrow \overline{a} \neq \overline{0}$\
Имеем $\overline{a}$ - ненулевой делитель нуля $\blacksquare$

Таким образом, при $m \geq 2$ кольцо $\Z_m$ будет либо полем, либо даже не являться областью целостности.\
Поля $\Z_p$, где $p$ - простое, называются полями Галуа и обозначаются $F_p$ или $GF(p)$

Частные случаи:\
$\Z_{0}$ можно отождествлять с $\Z$, тогда оно будет являться областью целостности, но не полем.\
$\Z_1 = \{0\}$ не имеет ненулевых делителей нуля, но не является областью целостности т.к. $\overline{1} = \overline{0}$
# Функция порядка
Функцией порядка в области целостности $R$ называется отображение\
$\phi : R\setminus\{0\} → \Z$ такое, что $a \neq b, b \ | \ a \Rightarrow \phi(a) \geq \phi(b)$\
Значение $\phi(a)$ будем называть порядком элемента а

Говорят, что в $R$ **справедлива теорема о делении с остатком**, если\
$\forall a,b \in R, b \neq 0 \ \exists q,r \in R : a = q\cdot b + r,\  r = 0 \vee \phi(r) < \phi(b)$

Область целостности $R$ называется **евклидовым кольцом**, если в ней существует функция порядка, относительно которой справедлива теорема о делении с остатком.

Следствие: из теоремы о делении целых чисел с остатком кольцо $\Z$ - евклидово, функцию порядка на $\Z$ задаёт функция абсолютной величины (модуль)
