# Основная теорема Арифметики (ОТА).
### Основная теорема Арифметики
$\forall n \in \N, n \neq 1$ число $n$ может быть записано в виде произведения простых чисел:\
$n = p_1 p_2 \dots p_n$, к тому же, эта запись единственна с точностью до перестановки множителей. Такое разложение так же называется разложением на простые множетели.

Доказать надо существование ($\exists$) и единственность $(!)$\
Доказательство:

($\exists$) Докажем по индукции:\
База индукции: т.к. $2$ - просто число, то для $2$ утверждение верно\
Индукционное предположение: $\gimel \ \forall n \in \N, 2 \leq n \leq m$ утверждение верно\
Индукционный переход: докажем, что в таком случае утверждение верно для $m+1$\
Если $m+1$ - простое число, то утверждение, очевидно, выполняется\
$\gimel m+1$ - не просто число, тогда $\exists a,b \in \N, \ 1 < a < m+1, \ 1 < b < m+1 : m + 1 = ab$\
По индукционному предположению, т.к. $a,b < m+1$, то $a = p_1 p_2 \dots p_k,\  b = q_1 q_2 \dots q_l$, где $p_1, p_2, \dots, p_k, q_1, q_2, \dots, q_l$ - простые числа, $k,l \in \N$\
Отсюда следует, что $m+1 = p_1 p_2 \dots p_k q_1 q_2 \dots q_l$

($!$) Докажем по индукции:\
$\gimel \ n = p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, $\forall i, j \in \N, p_i, p_j'$ = простые. Для определенности зафиксируем $r \leq r'$\
База индукции: $r = 1 \Rightarrow n = p_1 = p_1' p_2' \dots p_{r'}'$, т.к. $p_1$ простое, то оно не может являться произведением простых чисел, тогда $p_1 = p_1'$, $r = r'$\
Индукционное предположение: $\gimel\  \forall r :$ $1 < r \leq n-1$ разложение единственно и равно, то есть $\forall i \in \N \ p_i = p_i'$ и $r = r'$\
Индукционный переход: докажем, что утверждение верно для $r = n$\
$n = p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, т.к. $p_r$ простое, то, очевидно, $p_r \ | \ p_1' p_2' \dots p_{r'}'$\
Тогда $\exists k \in \N : p_k' = p_r$. Перенумеровав, если нужно, множетели, можем считать, что $k = r'$, тогда, поделив обе части равенства на $p_r$, получим $p_1 p_2 \dots p_{r-1} = p_1' p_2' \dots p_{r'-1}$\
По индукционному предположению эти разложения идентичны и $r - 1 = r' - 1 \Rightarrow r = r'$\
Домножив обратно обе части равенства на $p_r$, получим $p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, где выполнено $\forall i \in \N p_i = p_i'$ и $r = r' \ \ \blacksquare$ 

Перенумеровав сомножители так, чтобы они были попарно различны, получим:\
$n = p_1^{k_1} p_2^{k_2} \dots p_m^{k_m}$ - **каноническое** разложение числа $n$

# Простые числа. Бесконечность простых чисел
Число $p \in \N$ называется простым, если $p \ \vdots \ 1, \ p \ \vdots \ p, \ \forall x \in \N, x\neq 1, \ x \neq p \ \ p  \not{\vdots} \ x$\
(Нет делителей кроме 1 и самго себя).\
В противном случае число называется составным.

### Наименьший делитель числа
Утверждение: $\gimel n \in \N$, тогда наименьшим делителем числа $n$ будет просто число.\
Доказательство:\
$\gimel M$-  множество всех делителей числа $n$, отличных от 1\
$M$, как минимум, не пусто, т.к. $n \in M$, тогда в $M$ существует минимальное число q, такое, что $1 < q < n$ и $q \ | \ n$. Предположим, что $q$ не является простым числом, тогда  $\exists a \in \N : 1 < a < q$, $a \ | \ q$, но тогда $a \ | \ n \Rightarrow a$ - минимальное число в $M$, получили противоречие, т.к. $q$ - минимальное.\
Из противоречия следует, что $q$ - простое.

### Бесконечность простых чисел
Утверждение: Множество простых чисел бесконечно\
Доказательство:\
$\gimel$ множество простых чисел конечно и равно $P = \{p_1, \dots, p_n\}$\
Тогда рассмотрим число $N = (p_1 \cdot p_2 \cdot ... \cdot p_n) + 1$\
$\forall p \in P \ \ p \ | \ (p_1 \cdot p_2 \cdot ... \cdot p_n)$, но так же $p \not{|} \  1$\
Тогда получаем, что $N$ не делится ни на одно простое число, при этом $N$ само не является простым и больше $1$, что противоречит основной теореме Арифметики.\
Тогда $N$ - простое $\blacksquare$

# Взаимно простые числа
### Определение
Пара чисел называется **взаимно простой** (я буду обозначать $a \perp b$, но препод пишет словами обычно), если $НОД(a,b) = 1$\
Семейство называется взаимно простым, если $НОД{(a_i)}= 1$

### Свойства взаимной простоты

>[!info] Лемма о представлении НОД
$\forall a,b,c \in \Z \ \ НОД(a,b) = НОД(a + bc, b)$
Небольшое доказательство свойства 6 (Лемма)\
$\gimel \ M$ - множество общих делителей $a,b$, $M'$ - множество общих делителей $a + bc, b$\
Тогда $x \in M \Leftrightarrow (x \ | \ a, \ x \ | \ b) \Leftrightarrow (x \ | \ a + bc, \ x \ | \ b) \Leftrightarrow x \in M' \ \ \blacksquare$\
Пользуемся очевидным свойством: $x \ | \ a, \ x \ | \ b$, значит $x \ | \ a + b$, $x \ | \ a + 2b$ $\dots \ x \ | \ a + bc$

1. $НОД(a_i) = 1$ в $\Z \Leftrightarrow \ \exists \ (u_i)$ в $\Z : \displaystyle\sum_{i \in I} a_I \cdot u_i = 1$\
Доказательство(в две стороны):\
($\Rightarrow$) Частный случай теоремы о линейном представлении НОД\
($\Leftarrow$) $\gimel d = НОД(a_i), \ \ \forall  i \in I \ d \ | \ a_i \Rightarrow d \ | \ \displaystyle\sum_{i \in I} a_i \cdot u_i = 1 \Rightarrow d \ | \ 1 \Rightarrow d = 1$\
(Очевидно, если $d$ делит какие-то числа, то будет делить и их сумму.\
Коэффициенты при $a_i$ не влияют т.к. $\forall i \in I \ \ u_i \in \Z$)

2. $\gimel (a_i)$ - семейство, $НОД(a_i) = d, \ \  b_i := \dfrac{a_i}{d}$, тогда $НОД(b_i) = 1$\
Доказательство:\
По теоереме о линейном представлении НОД $d = \displaystyle\sum_{i \in I} a_i \cdot u_i \Rightarrow 1 = \dfrac{\displaystyle\sum_{i=1} a_i \cdot u_i}{d} = \displaystyle\sum_{i \in I} b_i \cdot u_i$, тогда по предыдущему свойству $НОД(b_i) = 1$

3. $\gimel (a_i)$ - семейство, если $\forall i \in I \ a_i \perp b$, то $\displaystyle\prod_{i \in I} a_i \ \perp \ b$\
Доказательство:\
По свойству (1) имеем $\forall i \in I \ НОД(a_i, b) = 1 \Rightarrow \exists v_i, u_i \in \Z \ : a_i u_i + b v_i = 1 \Rightarrow a_i u_i = 1 - b v_i$\
Перемножим равенства для всех $i \in I$, получим $(\displaystyle\prod_{i \in I} a_i) \cdot u = 1 - b v$, где $u = \displaystyle\prod_{i \in I} u_i$, а $v$ - какое-то число, полученное после выноса b за скобку.\
Из равенства выше получаем $(\displaystyle\prod_{i \in I} a_i) \cdot u + bv = 1$, по свойству (1) $НОД(\displaystyle\prod_{i \in I} a_i, b) = 1$

4. $a \perp c,\  c \ | \ ab \Rightarrow c \ | \ b$ (Также используется как Лемма о делении произведения)\
Доказательство:\
по свойству (1) $\exists u, v \in \Z : au + cv = 1$, домножим обе части равенства на b и получим\
$aub + cvb = b$, по условию $c \ | \ ab \Rightarrow c \ | \ aub$, а так же $c \ | \ cvb$, значит $c \ | \ b = aub + cvb$

5. $b \perp c,\ c \ | \ a,\  b \ | \ a \Rightarrow bc \ | \ a$\
Доказательство:\
$b \ | \ a \Rightarrow a = bx$, откуда по свойству (4) $c \ | \ x$ (т.к. $c \ | \ a$), тогда $x = cy \Rightarrow a = bcy \ \vdots \ bc$

6. $\gimel a,b,p \in \Z$, если $p \ | \ ab$, то $p \ | \ a \vee p \ | \ b$ (Лемме Евклида о делимости на простое число)\
Доказательство:\
$\gimel p \not{|} \ a$, тогда, т.к. $p$ - простое, то $НОД(a,p) = 1 \Rightarrow$ по свойству (4) $p \ | \ b$.\
Получаем $p \ | \ a \vee p \ | \ b$

 
# Наименьшее общее кратное (НОК). Связь НОД и НОК
### Определение НОК
НОК чисел $a_1, \dots, a_n$, называется такое число $k$, которое удовлетворяет следующим условиям:
1. $\forall i \in \{1, \dots, n\} \ \ a_i \ | \ k$
2. $\forall k' \in \Z \ \ \forall i \in \{1,\dots,n\} \ a_i \ | \ k \Rightarrow k \ | \ k'$
То есть $k$ является общим кратным и при этом точно является наименьшим

Множество НОК чисел $a_1, \dots, a_n$ обозначается $НОК\{a_1, \dots, a_n\}$.\
Очевидно, если $\exists i : a_i = 0$, то $НОК\{a_1, \dots, a_n\} = \{0\}$, и наоборот, если $\forall i \ a_i \neq 0$, то $НОК\{a_1, \dots, a_n\} = \{-k, k\}$, где $k$ - наименьшее положительное общее кратное.\
Именно положительное $k$ будет обозначаться как $НОК[a_1, \dots, a_n]$

### Связь НОД и НОК
Любые два целых числа можно записать в виде произведения одних и тех же простых чисел, если обусловиться допускать нулевые степени и $p_i^0 = 1$:\
$n = \pm \ p_1^{\alpha_1} \dots p_k^{\alpha_k}, \ m = \pm \ p_1^{\beta_1} \dots p_k^{\beta_k}$\
Тогда, очевидно:
1. $НОК(n,m) = p_1^{\gamma_1} \dots p_k^{\gamma_k}$, где $\forall i \in \N \ \gamma_i = \min(\alpha_i, \beta_i)$
2. $НОД(n,m) = p_1^{\delta_1} \dots p_l^{\delta_l}$, где $\forall i \in \N \ \delta_i = \max(\alpha_i, \beta_i)$

Из данных разложений вытекают следующие свойства:
1. $НОД(n,m) \ | \ n, \ НОД(n,m) \ | \ m, \ \ k \ | \ n \land k \ | \ m \Rightarrow k \ | \ НОД(n,m)$
2. $n \ | \ НОК(n,m),\  m \ | \ НОК(n,m),\ n \ | \ d \land m \ | \ d \Rightarrow НОК(n,m) \ | \ d$
3. $n,m > 0 \Rightarrow НОД(n,m) \cdot НОК(n,m) = nm$\
В частности, $n \perp m \Rightarrow НОК(n,m) = nm$ (т.к. $НОД(n,m) = 1$)

>[!info] Сравнимость
>### Определение
>$\gimel \ a, a', m \in \Z$, говорят, что $a$ сравнимо с $a'$ по модулю $m$, если $a-a' \ \vdots \ m$,\
обозначают $a \equiv a' (mod \ m)$, если $m$ фиксирован, то можно просто $a \equiv a'$\
Данное определение задаёт на множестве $\Z$ бинарную операцию сравнения
>
>Также можно считать, что $a \equiv a'$ если эти два числа дают одинаковые остатки при делении на $m$.
>
>$ac \equiv bc (mod \ m) \Rightarrow a \equiv b (mod \ m / НОД(c, m))$\
Доказательство: $\gimel \ d = НОД(m,c)$, тогда $c = d \cdot c_1, \ m = d \cdot m_1$, $c_1$ и $m_1$ взаимно простыы\
$ac \equiv bc (mod \ m) \Rightarrow ac - bc \ \vdots \ m \Rightarrow (a-b) \cdot c \ \vdots \ m \Rightarrow (a-b) \cdot d \cdot c_1 \ \vdots \ dm_1$\
$\Rightarrow (a-b) \cdot d \cdot c_1 = d \cdot m_1 \cdot x \Rightarrow$ $(a-b) \cdot c_1 = m_1 \cdot x$,\
 т.к. $c_1 \perp m_1$, то $(a - b) \ \vdots \ m_1 = m / d = m / НОД(m,c) \ \blacksquare$
>
>Новое, но все же очевидное свойство:
>$n \perp m, a \equiv a' (mod \ mn) \Leftrightarrow \begin{cases} a \equiv a' (mod \ m) \\ a \equiv a' (mod \ n)  \end{cases}$ \
Доказательство:\
($\Rightarrow$) "Очевидно"\
Если не очевидно: $a \equiv a' (mod \ mn) \Rightarrow xmn  + r \equiv ymn + r$\
Можно поделить на $m$, тогда получим $a \equiv a' (mod \ n)$, точно так же можем получить\
 $a \equiv a' (mod \ m)$ поделив на $n$
>
>($\Leftarrow$) Прямо следует ис свойства делимости взаимно простых чисел (свойство (5))

# Приведенная система вычетов. Функция Эйлера
### Приведенная система вычетов
$(\Z/m\Z)^*$ (я буду обозначать ($\Z_m)^*$) - группа, состоящая из всех классов вычетов $\overline{a_i}$, которые взаимно просты с $m$. Множество представителей из каждой такой группы называют приведенной системой вычетов. Таким образом:\
$\{a_1, \dots, a_n\}$ - приведенная система вычетов $\Leftrightarrow \{\overline{a_1}, \dots, \overline{a_n} \} = (\Z_m)^*$

Пример: для $\Z_{10} = \{0,1,\dots,9\}$ будет $(\Z_{10})^* = \{1,3,7,9\}$ 

### Функция Эйлера
Функцией Эйлера называется отображение $\varphi : \N \rightarrow \N$, такое что:\
$\forall \ a \in \N \ \varphi(a) = |\{x \in \N : 1 \leq x \leq a : НОД(x,a) = 1\}|$\
То есть количество всех взаимно простых натуральных чисел, не превосходящих $a$\
Функция Эйлера мультипликативна(без док-ва): $\varphi(ab) = \varphi(a)\varphi(b)$

$\gimel n = p_1^{k_1} \dots p_m^{k_m}$ - каноническое разложение $n$ $\in \N$ , тогда\
$\varphi(n) = p_1^{k_1-1}(p_1-1) \cdot ... \cdot p_m^{k_m-1}(p_m-1)$, поскольку, если $p \in \N$ - просто, то не взаимно просты с $p$ только те числа, которые на него делятся. Очевидно, что в промежутке $[1, p^k]$ имеется $\dfrac{p^k}{p} = p^{k-1}$ таких чисел.\
Тогда получаем, что $\varphi(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)$. По мультипликативности получаем общую формулу для числа $n$ из канонического разложения.
