# Множества
Множество - неупорядоченная совокупность различимых элементов, выделенных по определенном признаку.\
$\gimel \{a,b\} \text{ - множество}, a = b \Leftrightarrow \{a,b\} = \{a\}$ - различимость элементов обязательна

### Обозначения  
$A,B,C,D \dots$ - Множества, $a,b,c,d \dots$ - элементы множества.\
$a \in A$ - элемент a принадлежит (лежит в) множеству(e) A, $a \notin A$ - не принадлежит (не лежит)\
$\varnothing$ - пустое множество, не содержит в себе ни одного элемента, $|\varnothing| = 0$\
$U$ - универсум, общее множество из элементов которого составляются все остальные множетсва при решении определенной задачи. Грубо говоря ограничивает рассматриваемую область при решении

#### Способы задать множество:
1. $\{a,b,c,d,\cdots\}$ - напрямую вписать элементы
2. $\{a \in \N : условие\}$ - через условие, например $\{a \in \N : a \ mod \ 3 = 0\} = \{3,6,9,\cdots\}$
3. $\{1,2,3,...,100\}$ - интуитивно
4. $C = A \cup B$ - через операции с другими множествами 

### Часто встречаемые множества
$$
\N \text{ - натуральные числа, } = \{1,2,3,\cdots\} \\
\Z \text{ - целые числа, } = \{0,-1,1,-2,2,\cdots\} \\
\Bbb{Q} \text{ - рациональные числа, } = \{\frac{n}{m}: n \in \Z, m \in \N\} \\
\R \text{ -вещественные числа, } = \{\lim{\{a_n\}_{n=1}^{\infty}} : a_n \in \Bbb{Q}, \forall \epsilon \in \Bbb{Q}_{>0} \ \exists \ N \in \N : \forall n,m > N |a_n - a_m| < \epsilon\} \\
\Bbb{I} \text{ - Иррациональные числа, } = \{\Bbb{R} \setminus \Bbb{Q}\} \\
I\text{ (не путать с } \Bbb{I} \text{) } \text{ - множество индексов, } = \text{чаще всего } \N \text{(но не всегда)}\\
\Bbb{C} \text{ - комплексные числа, } = \{(a, b) = a + bi : a,b \in \R , i^2 = -1\} \\
$$

### Операции над множествами
1. $\cup$ - объединение, $X \cup Y = \{a: a \in X \ || \ a \in Y\}$
2. $\cap$ - пересечение, $X \cap Y = \{a: a \in X\ \& \ a \in Y\}$
3. $\setminus$ - разность, $X \setminus Y = \{a: a \in X \ \& \ a \notin Y \}$
4. $\overline{X}$ - дополнение, $\overline{X} = \{a \in U: a \notin X\}$
5. $\triangle$ - симметрическая разность, $X \triangle Y = \{A \setminus B\} \cup \{B \setminus A\}$

Операции объединения, пересечения и симметрической разности **коммутативны** и **ассоциативны**

#### Формулы Де-Моргана
$\overline{A \cup B} = \overline{A} \ \cap \ \overline{B}$, общий случай $\overline{\displaystyle\bigcup_{i \in I} A_i} = \displaystyle\bigcap_{i \in I} \overline{A_i}$ \
$\overline{A \cap B} = \overline{A} \ \cup\ \overline{B}$, общий случай $\overline{\displaystyle\bigcap_{i \in I} A_i} = \displaystyle\bigcup_{i \in I} \overline{A_i}$
# Подмножества
$X \subset Y \Leftrightarrow (\forall x \in X : x \in Y)$ - 
Мн-во X называется подмножеством Y, если все элементы из X лежат в Y

### Обозначения

1. $A \subset B$ - A является подмножеством B
2. $A \subsetneqq B$ - А является собственным подмножеством B, $\exists \ x \in B : x \notin A$
3. Некоторые преподы любят делать $\subset$ собственным подмножеством, а с помощью символа $\subseteq$ показывать что подмножество не обязательно собственное,по усмотрению лектора
4. $A \supset B$ - B содержит А (B является надмножеством А)


### Важные свойства
1. $\forall A \text{ - множество } \Rightarrow \varnothing \subset A$
2. $\varnothing \subset \varnothing$
3. $A = B \Leftrightarrow A\subset B \ \& \ B \subset A$
4. $\forall A,B \text{ - множества }, A \subset B \Rightarrow |A| \leq |B|$

### Множество всех подмножеств
$\gimel A$ - множество, множество его подмножеств записывается как $2^A$ потому что имеет мощность $2^{|A|}$(Доказательства не было).
$$
2^A = \{B : B \subset A\} \\
\gimel A = \{1,2,3\} \Rightarrow 2^A = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}
$$
# Отображение
### Определение
$(f, X, Y)$ - Отображение, в курсе математического анализа будет синонимом слова функция.

$f$ - некоторое правило преобразования элементов одного множества в элементы другого, отображение задано между двумя множествами $X$ и $Y$, если $\forall x \in X \ \exists! \ y \in Y : y = f(a)$
Обозначается $f: X → Y$

В нашем отображении элементы множества $X$ называются *прообразами*, а элементы множества $Y$- образами
### Свойства отображений
1. Инъекция - отображение инъективно, если $\forall x_1, x_2 \in X, x_1 \neq x_2 : f(x_1) \neq f(x_2)$
2. Сюръекция - отображение сюръективно, если $\forall y \in Y \ \exists \ x \in X : f(x) \in Y$
3. Биекция - отображение биективно, если оно инъективно и сюръективно. Также называется взаимооднозначным соответствием. Можно задать условие кванторами:
$$ \forall y \in Y \ \exists ! \ x \in X : f(x) \in Y $$

# Аксиомы Вещественных чисел
$(F, +, \cdot)$ - поле вещественных чисел. Аксиомы поля были затронуты на лекции поверхностно:

1. $a + b = b + a$ - коммутативность сложения
2. $a + (b + c) = (a + b) + c$ - ассоциативность сложеня
3. $\exists \ 0 : \forall x \in F : x + 0 = x$ - существование нейтрального по сложению элемента (нуля)
4. $\forall x \in F \ \exists! \ y \in F : y = -x$ - существование противоположного элемента
5. $a \cdot b = b \cdot a$ - коммутативность умножения
6. $(a \cdot b) \cdot c = a \cdot (b \cdot c)$ - ассоциативность умножения
7. $\exists \ 1 : \forall x \in F : x \cdot 1 = x$ - существование нейтрального по умножению элемента (единицы)
8. $\forall x \in F, x \neq 0 \ \exists ! \ y \in F : y = \frac{1}{x}$ - существование обратного элемента
9. $a \cdot (b + c) = ab + ac$ - связь сложения и умножения
10. Аксиома Архимеда: $\forall x, y \in \R, x,y > 0 \ \exists \ n \in \N : n\cdot x > y$
11. Аксиома о существовании супремума:

Пусть $E \subset \R, E \neq \emptyset$, $E$ ограничено сверху $<=> \forall x \in E \ \exists c \in \R : x \leq c$, тогда с - верхняя граница $E$. Если $E$ ограничено сверху, то $\exists \ c_0 : \forall x \in E : x \leq c_0$, если при этом $\forall c \in \R , c \ - \text{верхняя граница } E : c_0 \leq c, \text{ то } c_0 - \sup E$ (супремум, минимальная верхняя граница)
     
# Теорема о существовании inf (инфинума)
$\gimel  G \subset \R, G$ называется ограниченным снизу, если $\exists \ l \in \R : \forall \ y \in G \ y \geq l$, тогда l - нижняя граница $G$

Утверждение: \
$\gimel G \subset R, G$ ограничен снизу, тогда $\exists l_0 : \forall y \in G\ y \geq l_0$ и $\forall l \in \R, l$ - нижняя граница $G \ l_0 \geq l$   
$l_0$ - инфинум $G$, максимальная нижняя гранциа.

Доказательство: \
$\gimel E = \{x : \exists \ y \in G : x = -y\}$ \
$\gimel c_0 = \sup E$ \
$\forall x \in E \ x \leq c_0 \Leftrightarrow -x \geq -c_0 \Rightarrow \forall y \in G \ y \geq -c_0 \Rightarrow -c_0$ - нижняя граница $G$, назовем $-c_0$ как $l_0$ \
$\exists l : y \geq l \Leftrightarrow -y \leq -l \Rightarrow \forall x \in E \ x \leq -l$,тогда $-l$ - верхняя граница $E$ $\Rightarrow -l \geq c_0 \Rightarrow l \leq -c_0 = l_0$\
Получается, что любаяя нижняя граница будет меньше или равна $-c_0$, тогда $-c_0 = l_0$ - инфинум $\blacksquare$

# Последовательности
### Определение и обозначения
$(f, \N, \R)$ - последовательность(тройка из отображения, натуральных и вещественных чисел), часто записывают как $\{x_n\}^{\infty}_{n=1}$
$\forall n \in \N \ f(n) \in \R, x_n = f(n)$ 
$\gimel x \in \R, \forall \epsilon > 0 \ U(x), V(x), \omega(x)$ - обозначения окрестности $(x-\epsilon, x+\epsilon)$

### Предел последовательности
$\gimel \{x_n\}^{\infty}_{n=1}, a \in \R$
$\lim_{n \to \infty} = a \Leftrightarrow \forall \epsilon > 0 \ \exists \ N : \forall n > N \ |x_n - a| < \epsilon \ \Leftrightarrow \forall \ V(a) \ \exists \ N : \forall n > N x_n \in V(a)$
В таком случае а называют пределом последовательности, и говорят что последовательность *стремится* к а при n стремящемся к бесконечности

## Свойства пределов последовательности
### Единственность предела
Утверждение: \
$x_n \rightarrow_{n \rightarrow \infty} a$  и $x_n \rightarrow_{n \rightarrow \infty} b \Rightarrow a=b$

Доказательство: \
$\gimel x_n \rightarrow a, x_n \rightarrow b, a \neq b$ \
$b \neq a \Leftrightarrow |b-a| > 0, \text{Пусть} \ d = |b-a|$ \
$\gimel \epsilon = \frac{d}{4} > 0$ \
$x_n \rightarrow a \Rightarrow \exists \ N_1 : \forall n > N_1 \ |x_n -a| < \epsilon$ \
$x_n \rightarrow b \Rightarrow \exists \ N_2 : \forall n > N_2 \ |x_n-b| < \epsilon$ \
$\gimel n = N_1 + N_2 + 1$ (просто фиксируем порядковый номер который точно будет удовлетворять под оба условия) \
Из двух неравенств выше следует, что\
$|b-a| = |(b-x_n) + (x_n -a)| \leq |b - x_n| + |x_n - a| < \frac{d}{4} + \frac{d}{4} = \frac{d}{2}$ \
Получается $|b-a| = d < \frac{d}{2}$ - противоречие, значит a = b $\blacksquare$
