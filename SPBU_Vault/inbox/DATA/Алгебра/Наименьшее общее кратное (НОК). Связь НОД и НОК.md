# Наименьшее общее кратное (НОК). Связь НОД и НОК
### Определение НОК
НОК чисел $a_1, \dots, a_n$, называется такое число $k$, которое удовлетворяет следующим условиям:
1. $\forall i \in \{1, \dots, n\} \ \ a_i \ | \ k$
2. $\forall k' \in \Z \ \ \forall i \in \{1,\dots,n\} \ a_i \ | \ k \Rightarrow k \ | \ k'$
То есть $k$ является общим кратным и при этом точно является наименьшим

Множество НОК чисел $a_1, \dots, a_n$ обозначается $НОК\{a_1, \dots, a_n\}$.\
Очевидно, если $\exists i : a_i = 0$, то $НОК\{a_1, \dots, a_n\} = \{0\}$, и наоборот, если $\forall i \ a_i \neq 0$, то $НОК\{a_1, \dots, a_n\} = \{-k, k\}$, где $k$ - наименьшее положительное общее кратное.\
Именно положительное $k$ будет обозначаться как $НОК[a_1, \dots, a_n]$

### Связь НОД и НОК
Любые два целых числа можно записать в виде произведения одних и тех же простых чисел, если обусловиться допускать нулевые степени и $p_i^0 = 1$:\
$n = \pm \ p_1^{\alpha_1} \dots p_k^{\alpha_k}, \ m = \pm \ p_1^{\beta_1} \dots p_k^{\beta_k}$\
Тогда, очевидно:
1. $НОК(n,m) = p_1^{\gamma_1} \dots p_k^{\gamma_k}$, где $\forall i \in \N \ \gamma_i = \max(\alpha_i, \beta_i)$
2. $НОД(n,m) = p_1^{\delta_1} \dots p_l^{\delta_l}$, где $\forall i \in \N \ \delta_i = \min(\alpha_i, \beta_i)$

Из данных разложений вытекают следующие свойства:
1. $НОД(n,m) \ | \ n, \ НОД(n,m) \ | \ m, \ \ k \ | \ n \land k \ | \ m \Rightarrow k \ | \ НОД(n,m)$
2. $n \ | \ НОК(n,m),\  m \ | \ НОК(n,m),\ n \ | \ d \land m \ | \ d \Rightarrow НОК(n,m) \ | \ d$
3. $n,m > 0 \Rightarrow НОД(n,m) \cdot НОК(n,m) = nm$\
В частности, $n \perp m \Rightarrow НОК(n,m) = nm$ (т.к. $НОД(n,m) = 1$)
