# Наибольший общий делитель
### Определение
$\gimel \ (a,b)$ - пара чисел, $a, b \in \Z$\
Наибольшим общем делителем этой пары чисел (в дальнейшем $НОД(a, b)$) называется $d \in \Z$, такое что $d \ | \ a, \ d \ | \ b,  \ \ \forall x \in \Z \ \ \  x \ | \ a, \ x \ | \ b \ \Rightarrow \ x \ | \ d$\

Аналогично, для семейства $(a_i)_{i \in I}$ $НОД(a_i)$ будет $d \in \Z : \forall i \in I \ \ d \ | \ a_i$,\
$\forall x \in \Z$ если $\forall i \in I \ \ x \ | \ a_i$, то $x \ | \ d$

Пара чисел называется **взаимно простой** (я буду обозначать $a \perp b$, но препод пишет словами обычно), если $НОД(a,b) = 1$

### Свойства НОД
1. $НОД(ca,cb) = c \cdot НОД(a,b)$
2. $a \perp b \Rightarrow НОД(a,c) \cdot НОД(b,c) = НОД(a \cdot b, c)$
3. $НОД(a, 0) = a$, $НОД(a,1) = 1$
4. $b \ | \ a \Rightarrow НОД(a, b) = b$
5. $a \perp c \Rightarrow НОД(a,b,c) = НОД(b,c)$
6. $\forall a,b,c \in \Z \ \ НОД(a,b) = НОД(a + bc, b)$
Небольшое доказательство свойства 6 (Лемма)\
$\gimel \ M$ - множество общих делителей $a,b$, $M'$ - множество общих делителей $a + bc, b$\
Тогда $x \in M \Leftrightarrow (x \ | \ a, \ x \ | \ b) \Leftrightarrow (x \ | \ a + bc, \ x \ | \ b) \Leftrightarrow x \in M' \ \ \blacksquare$\
Пользуемся очевидным свойством: $x \ | \ a, \ x \ | \ b$, значит $x \ | \ a + b$, $x \ | \ a + 2b$ $\dots \ x \ | \ a + bc$

### Два наибольших общих делителя
Предложение: $\gimel d - НОД(a,b)$ (или $НОД(a_i)$), тогда $d' - НОД(a,b)$ (или $НОД(a_i)$) $\Leftrightarrow$\
$\Leftrightarrow$ $d \sim d'$ (ассоциированы)\
Доказать надо в обе стороны

Доказательство: ($\Rightarrow$) $d, d' - НОД(a,b)$ (или $НОД(a_i)$) $\Rightarrow d \ | \ d', \ d' \ | \ d$\
Тогда по определению $\sim$ получаем $d \sim d'$

($\Leftarrow$) $\gimel \ d \sim d'$\
$d \ \vdots \ d' \Rightarrow d'$ - общий делитель пары (или семейства)\
$d' \ \vdots \ d \Rightarrow d'$ делится и на все другие общие делители (т.к. $d$ делится на них)\
Из двух утверждений получаем, что $d'$ - наибольший общий делитель пары (или семейства) $\blacksquare$

Данным предложением бы доказали, что любой $d' \sim d$ тоже является НОД.\
В частности, $-d \sim d$, из чего получаем, что если $d \neq 0$, то имеем 2 $НОД$ для любой пары (или семейства). В случае с $d = 0$ $НОД$ один и равен $0$. Менять обозначений не будем, под $НОД(a,b)$ (или $НОД(a_i)$) будем иметь любой из двух наибольших общих делителей.
