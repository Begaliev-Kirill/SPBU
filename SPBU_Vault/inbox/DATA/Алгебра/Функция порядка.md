# Функция порядка
Функцией порядка в области целостности $R$ называется отображение\
$\phi : R\setminus\{0\} → \Z$ такое, что $a \neq b, b \ | \ a \Rightarrow \phi(a) \geq \phi(b)$\
Значение $\phi(a)$ будем называть порядком элемента а

Говорят, что в $R$ **справедлива теорема о делении с остатком**, если\
$\forall a,b \in R, b \neq 0 \ \exists q,r \in R : a = q\cdot b + r,\  r = 0 \vee \phi(r) < \phi(b)$

Область целостности $R$ называется **евклидовым кольцом**, если в ней существует функция порядка, относительно которой справедлива теорема о делении с остатком.

Следствие: из теоремы о делении целых чисел с остатком кольцо $\Z$ - евклидово, функцию порядка на $\Z$ задаёт функция абсолютной величины (модуль)
