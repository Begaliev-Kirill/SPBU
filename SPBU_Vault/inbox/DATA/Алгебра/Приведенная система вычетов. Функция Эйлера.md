# Приведенная система вычетов. Функция Эйлера
### Приведенная система вычетов
$(\Z/m\Z)^*$ (я буду обозначать ($\Z_m)^*$) - группа, состоящая из всех классов вычетов $\overline{a_i}$, которые взаимно просты с $m$. Множество представителей из каждой такой группы называют приведенной системой вычетов. Таким образом:\
$\{a_1, \dots, a_n\}$ - приведенная система вычетов $\Leftrightarrow \{\overline{a_1}, \dots, \overline{a_n} \} = (\Z_m)^*$

Пример: для $\Z_{10} = \{0,1,\dots,9\}$ будет $(\Z_{10})^* = \{1,3,7,9\}$ 

### Функция Эйлера
Функцией Эйлера называется отображение $\varphi : \N \rightarrow \N$, такое что:\
$\forall \ a \in \N \ \varphi(a) = |\{x \in \N : 1 \leq x \leq a : НОД(x,a) = 1\}|$\
То есть количество всех взаимно простых натуральных чисел, не превосходящих $a$\
Функция Эйлера мультипликативна(без док-ва): $\varphi(ab) = \varphi(a)\varphi(b)$

$\gimel n = p_1^{k_1} \dots p_m^{k_m}$ - каноническое разложение $n$ $\in \N$ , тогда\
$\varphi(n) = p_1^{k_1-1}(p_1-1) \cdot ... \cdot p_m^{k_m-1}(p_m-1)$, поскольку, если $p \in \N$ - просто, то не взаимно просты с $p$ только те числа, которые на него делятся. Очевидно, что в промежутке $[1, p^k]$ имеется $\dfrac{p^k}{p} = p^{k-1}$ таких чисел.\
Тогда получаем, что $\varphi(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)$. По мультипликативности получаем общую формулу для числа $n$ из канонического разложения.
