# Основная теорема Арифметики (ОТА).
### Основная теорема Арифметики
$\forall n \in \N, n \neq 1$ число $n$ может быть записано в виде произведения простых чисел:\
$n = p_1 p_2 \dots p_n$, к тому же, эта запись единственна с точностью до перестановки множителей. Такое разложение так же называется разложением на простые множетели.

Доказать надо существование ($\exists$) и единственность $(!)$\
Доказательство:

($\exists$) Докажем по индукции:\
База индукции: т.к. $2$ - просто число, то для $2$ утверждение верно\
Индукционное предположение: $\gimel \ \forall n \in \N, 2 \leq n \leq m$ утверждение верно\
Индукционный переход: докажем, что в таком случае утверждение верно для $m+1$\
Если $m+1$ - простое число, то утверждение, очевидно, выполняется\
$\gimel m+1$ - не просто число, тогда $\exists a,b \in \N, \ 1 < a < m+1, \ 1 < b < m+1 : m + 1 = ab$\
По индукционному предположению, т.к. $a,b < m+1$, то $a = p_1 p_2 \dots p_k,\  b = q_1 q_2 \dots q_l$, где $p_1, p_2, \dots, p_k, q_1, q_2, \dots, q_l$ - простые числа, $k,l \in \N$\
Отсюда следует, что $m+1 = p_1 p_2 \dots p_k q_1 q_2 \dots q_l$

($!$) Докажем по индукции:\
$\gimel \ n = p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, $\forall i, j \in \N, p_i, p_j'$ = простые. Для определенности зафиксируем $r \leq r'$\
База индукции: $r = 1 \Rightarrow n = p_1 = p_1' p_2' \dots p_{r'}'$, т.к. $p_1$ простое, то оно не может являться произведением простых чисел, тогда $p_1 = p_1'$, $r = r'$\
Индукционное предположение: $\gimel\  \forall r :$ $1 < r \leq n-1$ разложение единственно и равно, то есть $\forall i \in \N \ p_i = p_i'$ и $r = r'$\
Индукционный переход: докажем, что утверждение верно для $r = n$\
$n = p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, т.к. $p_r$ простое, то, очевидно, $p_r \ | \ p_1' p_2' \dots p_{r'}'$\
Тогда $\exists k \in \N : p_k' = p_r$. Перенумеровав, если нужно, множетели, можем считать, что $k = r'$, тогда, поделив обе части равенства на $p_r$, получим $p_1 p_2 \dots p_{r-1} = p_1' p_2' \dots p_{r'-1}$\
По индукционному предположению эти разложения идентичны и $r - 1 = r' - 1 \Rightarrow r = r'$\
Домножив обратно обе части равенства на $p_r$, получим $p_1 p_2 \dots p_r = p_1' p_2' \dots p_{r'}'$, где выполнено $\forall i \in \N p_i = p_i'$ и $r = r' \ \ \blacksquare$ 

Перенумеровав сомножители так, чтобы они были попарно различны, получим:\
$n = p_1^{k_1} p_2^{k_2} \dots p_m^{k_m}$ - **каноническое** разложение числа $n$
