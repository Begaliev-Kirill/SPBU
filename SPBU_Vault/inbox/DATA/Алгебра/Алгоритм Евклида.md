# Алгоритм Евклида
Алгоритм Евклида полностью построен на свойстве номер (6) НОДа, свойство будет использоваться как Лемма 

$\gimel (a,b) : a,b \in \Z, \ \ b = 0 \Rightarrow НОД(a,b) = a$\
$\gimel \ b \neq 0$, по теореме о делении целых чисел с остатком $a = b \cdot q_1 + r_1, 0 \leq r_1 < |b|$\
По лемме $НОД(a,b) = НОД(b\cdot q_1 + r_1, b) = НОД(r_1, b)$\
Это и есть один шаг алгоритма, выражая далее одно значение из пары через другое мы получим строго убывающую последовательность $|b| \geq r_1 \geq r_2 \geq \dots \geq 0$\
Такая последовательность, очевидно, конечна и ограничена снизу.\
Следующий шаг не будет возможен, если $r_{k+1} = 0$, то есть мы применяем алгоритм до тех пор, пока не получим пару значений $НОД(r_k, 0) = r_k$\
Выходит, что $НОД(a,b) = r_k$ (Если $r_1 = 0$, то $a \ \vdots \ b \Rightarrow НОД(a,b) = b$)

Схема для лучшего понимания алгоритма:\
$a = b \cdot q_1 + r_1$\
$b = r_1 \cdot q_2 + r_2$\
$r_1 = r_2 \cdot q_3 + r_3$\
$\dots$
$r_{k-2} = r_{k-1} \cdot q_{k} + r_k$\
$r_{k-1} = r_k \cdot q_{k+1} + 0$ (на этом шаге $r_{k+1} = 0$)
