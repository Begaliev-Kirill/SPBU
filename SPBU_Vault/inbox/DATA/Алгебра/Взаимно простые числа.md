# Взаимно простые числа
### Определение
Пара чисел называется **взаимно простой** (я буду обозначать $a \perp b$, но препод пишет словами обычно), если $НОД(a,b) = 1$\
Семейство называется взаимно простым, если $НОД{(a_i)}= 1$

### Свойства взаимной простоты
1. $НОД(a_i) = 1$ в $\Z \Leftrightarrow \ \exists \ (u_i)$ в $\Z : \displaystyle\sum_{i \in I} a_I \cdot u_i = 1$\
Доказательство(в две стороны):\
($\Rightarrow$) Частный случай теоремы о линейном представлении НОД\
($\Leftarrow$) $\gimel d = НОД(a_i), \ \ \forall  i \in I \ d \ | \ a_i \Rightarrow d \ | \ \displaystyle\sum_{i \in I} a_i \cdot u_i = 1 \Rightarrow d \ | \ 1 \Rightarrow d = 1$\
(Очевидно, если $d$ делит какие-то числа, то будет делить и их сумму.\
Коэффициенты при $a_i$ не влияют т.к. $\forall i \in I \ \ u_i \in \Z$)

2. $\gimel (a_i)$ - семейство, $НОД(a_i) = d, \ \  b_i := \dfrac{a_i}{d}$, тогда $НОД(b_i) = 1$\
Доказательство:\
По теоереме о линейном представлении НОД $d = \displaystyle\sum_{i \in I} a_i \cdot u_i \Rightarrow 1 = \dfrac{\displaystyle\sum_{i=1} a_i \cdot u_i}{d} = \displaystyle\sum_{i \in I} b_i \cdot u_i$, тогда по предыдущему свойству $НОД(b_i) = 1$

3. $\gimel (a_i)$ - семейство, если $\forall i \in I \ a_i \perp b$, то $\displaystyle\prod_{i \in I} a_i \ \perp \ b$\
Доказательство:\
По свойству (1) имеем $\forall i \in I \ НОД(a_i, b) = 1 \Rightarrow \exists v_i, u_i \in \Z \ : a_i u_i + b v_i = 1 \Rightarrow a_i u_i = 1 - b v_i$\
Перемножим равенства для всех $i \in I$, получим $(\displaystyle\prod_{i \in I} a_i) \cdot u = 1 - b v$, где $u = \displaystyle\prod_{i \in I} u_i$, а $v$ - какое-то число, полученное после выноса b за скобку.\
Из равенства выше получаем $(\displaystyle\prod_{i \in I} a_i) \cdot u + bv = 1$, по свойству (1) $НОД(\displaystyle\prod_{i \in I} a_i, b) = 1$

4. $a \perp c,\  c \ | \ ab \Rightarrow c \ | \ b$ (Также используется как Лемма о делении произведения)\
Доказательство:\
по свойству (1) $\exists u, v \in \Z : au + cv = 1$, домножим обе части равенства на b и получим\
$aub + cvb = b$, по условию $c \ | \ ab \Rightarrow c \ | \ aub$, а так же $c \ | \ cvb$, значит $c \ | \ b = aub + cvb$

5. $b \perp c,\ c \ | \ a,\  b \ | \ a \Rightarrow bc \ | \ a$\
Доказательство:\
$b \ | \ a \Rightarrow a = bx$, откуда по свойству (4) $c \ | \ x$ (т.к. $c \ | \ a$), тогда $x = cy \Rightarrow a = bcy \ \vdots \ bc$

6. $\gimel a,b,p \in \Z$, если $p \ | \ ab$, то $p \ | \ a \vee p \ | \ b$ (Лемме Евклида о делимости на простое число)\
Доказательство:\
$\gimel p \not{|} \ a$, тогда, т.к. $p$ - простое, то $НОД(a,p) = 1 \Rightarrow$ по свойству (4) $p \ | \ b$.\
Получаем $p \ | \ a \vee p \ | \ b$
