# Подмножества
$X \subset Y \Leftrightarrow (\forall x \in X : x \in Y)$ - 
Мн-во X называется подмножеством Y, если все элементы из X лежат в Y

### Обозначения

1. $A \subset B$ - A является подмножеством B
2. $A \subsetneqq B$ - А является собственным подмножеством B, $\exists \ x \in B : x \notin A$
3. Некоторые преподы любят делать $\subset$ собственным подмножеством, а с помощью символа $\subseteq$ показывать что подмножество не обязательно собственное,по усмотрению лектора
4. $A \supset B$ - B содержит А (B является надмножеством А)


### Важные свойства
1. $\forall A \text{ - множество } \Rightarrow \varnothing \subset A$
2. $\varnothing \subset \varnothing$
3. $A = B \Leftrightarrow A\subset B \ \& \ B \subset A$
4. $\forall A,B \text{ - множества }, A \subset B \Rightarrow |A| \leq |B|$

### Множество всех подмножеств
$\gimel A$ - множество, множество его подмножеств записывается как $2^A$ потому что имеет мощность $2^{|A|}$(Доказательства не было).
$$
2^A = \{B : B \subset A\} \\
\gimel A = \{1,2,3\} \Rightarrow 2^A = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}
$$
