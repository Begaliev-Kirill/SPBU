# Отношения
### Определение и обозначения
$\gimel A, B \text{ - множества }, \Gamma \subset A \times B$\
$\cal C := (A,B, \Gamma)$ - соответствие, $a \cal C b \Leftrightarrow (a,b) \in \Gamma$, $a \cal C b$ - а в отношении с b\
(1) Если $\cal C$ задано на одном множестве, то оно назвыается отношением (Геометрия)\
(2) $\cal C$ сразу называется отношением и $\rho = \cal C, R = \Gamma$, а отношение на одном множестве называется бинарным (Алгебра)\

Для удобства я выберу обозначения (2) с алгебры и буду использовать их

### Свойства бинарных отношений
1. Рефлексивность $\Leftrightarrow \forall a \in A \ a \rho a$
2. Симметричность $\Leftrightarrow \forall a,b \in A  \ a\rho b \Rightarrow b \rho a$
3. Транзитивность $\Leftrightarrow \forall a,b,c \in A \ a\rho b, b\rho c \Rightarrow a\rho c$

### Отношение эквивалентности
Бинарное отношение называется эквивалентным, если оно (1-3) рефлексивно, симметрично и транзитивно. Обозначается символом $\sim$\
$\widetilde{x} = \{a \in A : a \sim x \}$ - класс эквивалентности элемента x, по рефлексивности $\forall x \in A\ x \in \widetilde{x}$\
$\gimel \ a_0 \in \widetilde{a} \Rightarrow a_0 \sim a.\ \gimel\ x \in \widetilde{a} \Rightarrow x \sim a \Rightarrow x \sim a_0$ по транзитивности тогда $x\in \widetilde{a_0} \Rightarrow \text{т.к. верно } \forall x \in \widetilde{a} \text{ , то } \widetilde{a_0} \subset \widetilde{a}$ \
В обратную сторону таким же образом можем доказать что $\widetilde{a} \subset \widetilde{a_0}$, из чего можем сделать вывод, что $\widetilde{a_0} = \widetilde{a}$\
Рассмотрим случайный $x \in A$, тогда возможно два случая:
1. $x \sim a \Rightarrow \widetilde{x} = \widetilde{a}$
2. $x \nsim a. \ \forall  x_0 \in \widetilde{x}: x_0 \sim x \Rightarrow x_0 \nsim a \Rightarrow x_0 \notin \widetilde{a} \Rightarrow \widetilde{x} \cap \widetilde{a} = \varnothing$

Т.к. $\forall a \in A : a \in \widetilde{a}$, то $A = \displaystyle\bigcup_{i \in I} \widetilde{a_i}$, учитывая два случая, можем сделать вывод, что множество $A$ можно разбить на непересекающиеся классы эквивалентности\
$A/\sim$ - разбиение $A$ на классы эквивалентности(фактор множество),\
$A/ \sim \ = \{\widetilde{a_i} : a_i \in A, a_i \neq a_j \ \forall i,j \in I, i \neq j\}$ \
А так же $a \sim b \Leftrightarrow \exists \ i \in I : a_i \in A,  a \in \widetilde{a_i}, b \in \widetilde{a_i}$
