# Предел функции
### Точка сгущения
Напомню, что $\overline{\R} = (\R, -\infty, +\infty)$, $\omega(\alpha)$ - окрестность около точки $\alpha$\
$\gimel E \subset \overline{\R}, \alpha \in \overline{\R}$, при этом $\alpha$ не обязательно $\in E$, тогда:\
$\alpha$ - точка сгущения для $E \Leftrightarrow \forall \omega(\alpha), \alpha \in \omega(\alpha) \ \ \ \exists x \in E, x \neq \alpha : x \in \omega(\alpha)$\
Второй способ записи: $\forall \omega(\alpha), \alpha \in \omega(\alpha) \ \ \exists x \in E \cap \omega(\alpha), x \neq \alpha$\
По простому: $\alpha$ - точка сгущения, если вокруг неё есть точки из $E$ на бесконечно близком расстоянии.

### Лемма о точке сгущения 
$\gimel E \subset \overline{\R}, \ \alpha$ - точка сгущения $E$, тогда $\exists \{x_n\}_{n=1}^{\infty} : \forall n \in \N \ \ \ x_n \in E, x_n \neq \alpha$ и $\{x_n\} \rightarrow \alpha$,\
то есть всегда можно выделить последовательность, сходящуюся к $\alpha$

Небольшое доказательство:\
Рассмотрим $a \in \overline{\R}, \ \omega_n(\alpha) = (\alpha - \frac{1}{n}, \alpha + \frac{1}{n}), \ \ \omega_n(+\infty) = (n, +\infty),\ \  \omega_n(-\infty) = (-\infty,n)$\
Тогда по определению точки сгущения $\forall n \in \N \ \ \exists x_n \in \omega_n(\alpha) \cap E, \ x_n \neq \alpha$\
Соответственно, закрепив для каждого $n$ какой-то $x_n$ получим $\{x_n\}$ по определению предела через окрестности.

### Определение предела функции
#### Определение по Коши (через $\varepsilon$ и $\delta$)
$\gimel E \subset \overline{\R}, \ \alpha \in \overline{\R},\ A \in \overline{\R}, \ f : E \rightarrow \R$, тогда:\
$f(x) \xrightarrow[x \rightarrow \alpha]{} A \Leftrightarrow A$ - предел $f(x)$ при $x \rightarrow \alpha$, то есть:\
$\forall \varepsilon > 0 \ \ \exists \delta > 0 : \forall x \in (\alpha - \delta, \alpha + \delta) \cap E, x \neq \alpha \ \ \ |f(x) - A| < \varepsilon$\
Запись через окрестности:\
$\forall G(A) \ \ \exists \omega(\alpha) : \forall x \in \omega(\alpha) \cap E, \neq \alpha \ \ \ f(x) \in G(A)$ ($G(A)$ - окрестность точки $A$)

Важно заметить, что $A$ не всегда является $f(\alpha)$ - в качестве примера можно рассмотреть функцию $f(x) = \begin{cases} 2, x \neq \alpha \\ 10, x = \alpha  \end{cases}$, в данном случае по определению легко доказывается, что $f(x) \xrightarrow[x \rightarrow \alpha]{} 2$.

##### Локальная ограниченность функции (в окрестности точки сгущения)
$\gimel \ E \subset \overline{\R},\ A \in \overline{\R}, \ \alpha \in \overline{\R}, \ \alpha$ - тчока сгущения $E$, тогда:\
$f(x) \xrightarrow[x \rightarrow \alpha]{} A \Rightarrow \ \exists \omega(\alpha), \ c > 0 : \ \forall x \in \omega(\alpha) \cap E, x \neq \alpha \ \ \ |f(x)| \leq c$\
То есть значения $f(x)$ вокруг точки $\alpha$ при необходимости можно ограничить константой $c$

Доказательство:\
$\gimel \varepsilon = 1$, тогда $\exists \omega(\alpha) : \forall x \in \omega(\alpha) \cap E, x \neq \alpha \ \ \ |f(x) - A| < 1$ (По определению по Коши),\
тогда $|f(x)| = |f(x) - A + A| < |f(x) - A| + |A| < 1 + |A|$\
Задав $c = 1 + |A|$, получим искомую константу $\blacksquare$

### Определение предела функции по Гейне
Ключевая идея теоремы - связать предел функции с пределом последовательности.\
Тогда можно будет все свойства пределов последовательностей перенести на предел функции.

Теорема:\
$\gimel E \subset \overline{\R},\ A \in \overline{\R},\ \alpha \in \overline{\R},\ \alpha$ - точка сгущения $E$, $f : E \rightarrow \R$, тогда:\
$f(x) \xrightarrow[x \rightarrow \alpha]{} A \Leftrightarrow \forall \{x_n\}$ таких, что $\forall n \in \N \ \ x_n \in E, x_n \neq \alpha$ и $x_n \xrightarrow[n \rightarrow \infty]{} \alpha$ будет верно, что\
$\exists$ предел $f(x_n)$ при $n \rightarrow \infty$, при этом окажется, что $f(x_n) \xrightarrow[n \rightarrow \infty]{} A$

То есть, независимо от того, каким образом наши $x_n$ приближаются к $\alpha$, мы точно знаем, что функция будет стремиться к одному и тому же $A$

Доказательство (необходимость ($\Rightarrow$) и достаточность ($\Leftarrow$)):\
$(\Rightarrow)$ Зафиксируем случайную последовательность $\{x_n\} : x_n \xrightarrow[n \rightarrow \infty]{} \alpha$.\
Хотим показать, что $f(x_n) \xrightarrow[n \rightarrow \infty]{} A$.\
$\forall G(A) \ \ \exists \omega(\alpha) \ : \ \forall x \in \omega(\alpha) \cap E, x \neq \alpha \ \ \ f(x) \in G(A)$ по определению сходящейся функции.\

$\exists N \in \N : \ \forall n \in \N, \ n > N \ \ \ x_n \in \omega(\alpha),\ x_n \in E,\ x_n \neq \alpha$ (очевидно по фиксированной $\{x_n\}$ и определению предела) $\Rightarrow$ $x_n \in \omega(\alpha) \cap E \Rightarrow f(x_n) \in G(A)$, тогда по определению предела функции $f(x_n) \xrightarrow[n \rightarrow \infty]{} A$

($\Leftarrow$) Доказывать достаточность будем от противного\
$\gimel \ \ \{x_n\}$ - последовательность, такая что $\forall n \in \N \ \ x_n \in E, x_n \neq \alpha$ и $\{x_n\} \rightarrow \alpha$,\
предел $f(x_n)$ при $n \rightarrow \infty$ обозначим за $A$, при этом предположим, что $f(x) \xrightarrow[x \rightarrow \alpha]{} A$ неверно.\
$\exists G_0(A): \ \ \forall \omega(\alpha) \ \ \exists x_n' \in \omega_n(\alpha), x_n' \neq \alpha \ \ : \ \ f(x) \notin G_0(A)$ по предположению

Создадим из всех таких $x_n'$ последовательность $\{x_n'\}$\
Очевидно, что $\{x_n'\} \rightarrow \alpha$ (по определению предела через окрестности), тогда\
$\exists \displaystyle\lim_{n \to \infty} {f(x_n')} = B \in \overline{\R}, \ \ f(x_n') \notin G_0(A) \Rightarrow B \neq A$

Создадим третью последовательность $\{t_n\}$, где $t_{2n+1} = x_n, \ t_{2n} = x_n'$ (четные из одной последовательности, нечетные из другой)\
Очевидно, $\{t_n\} \rightarrow \alpha, \ \forall n \in \N \ \ \ t_n \in E, t_n \neq \alpha$\
Обозначим $\displaystyle\lim_{n \to \infty} {f(t_n)}$ за $C \in \overline{\R}$

Зафиксируем $\varepsilon = \dfrac{1}{4} \cdot |A-B|$ ($B - A \neq 0$ т.к. было доказано выше что $B \neq A$)\
$\gimel N_1 \ : \ \forall n \in \N, \ n > N_1 \ \ \ |f(x_n) - A| < \varepsilon$\
$\gimel N_2 \ : \ \forall n \in \N, \ n > N_2 \ \ \ |f(x_n') - B| < \varepsilon$\
$\gimel N_3 \ : \ \forall n \in \N, \ n > N_3 \ \ \ |f(t_n) - C| < \varepsilon$\
И зафиксируем такой $N = \max(2N_1, 2N_2, N_3)$, начиная с которого $\forall n \in \N$ будут выполнены все три неравенства выше.

Далее хотим используя наше построение $\{t_n\}$ показать противоречие.\
$\gimel n \in \N, \ n > N, \ n = 2m-1, \ \ тогда \ m > N_1$ (из-за фиксирования $N$)\
$|f(t_{2m-1}) - C| = |f(x_m) - C| = |f(x_m) - A + A - C| \geq |A - C| - |f(x_m) - A| > |A - C| - \varepsilon$\
При этом $|f(t_{n}) - C| < \varepsilon$, получается $|A - C| - \varepsilon < |f(t_{n}) - C| < \varepsilon$,\
тогда $|A - C| - \varepsilon < \varepsilon \Rightarrow |A - C| < 2 \varepsilon$

$\gimel n \in \N, \ n > N, \ n = 2m,$ тогда $m > N_2$\
$|f(t_{2m}) - C| = |f(x_n') - B + B - C| \geq |B-C| - |f(x_n') - B| > |B-C| - \varepsilon$\
Получаем $|B-C| - \varepsilon < |f(t_n) - C| < \varepsilon \Rightarrow |B-C| < 2 \varepsilon$

$|A - B| = |A - C + C - B| \leq |A - C| + |C - B|$\
По доказанным неравенствам выше $|A - C| + |C - B| < 2 \varepsilon + 2 \varepsilon = 4 \varepsilon$\
Изначально мы задали $\varepsilon = \dfrac{1}{4} \cdot |A-B|$, получается $4 \varepsilon = |A-B|$\
$|A-B| < |A-B|$ - противоречие, тогда $f(x) \xrightarrow[x \rightarrow \alpha]{} A \ \ \blacksquare$

### Свойства пределов функций
Абсолютно все из них доказываются через свойства пределов, нужно просто выразить предел функции по Гейне через предел последовательности, поэтому будет приведено только 1 доказательство в качестве примера доказательства свойства.

Фиксируем $E \subset \overline{\R}, x \rightarrow \alpha$ для всех свойств ниже
1. $f(x) \xrightarrow[x \rightarrow \alpha]{} A, \ f(x) \xrightarrow[x \rightarrow \alpha]{} B \Rightarrow A = B$\
Доказательство: $\gimel \{x_n\} : \ \forall n \in \N \ \ x_n \in E, x_n \neq \alpha, \{x_n\} \rightarrow \alpha \Rightarrow \exists \displaystyle\lim_{n \to \infty} {x_n} = c$, по теореме о единственности предела последовательности $A=B=c \ \ \blacksquare$
2. $\forall x \in E \ \ f(x) = c_0 \in \R \Rightarrow f(x) \xrightarrow[x \rightarrow \alpha]{} c_0$
3. $\displaystyle\lim_{x \rightarrow \alpha} {cf(x)} = c \cdot \displaystyle\lim_{x \to \alpha} {f(x)}$
4. $\displaystyle\lim_{x \to \alpha} {f(x) + g(x)} = \displaystyle\lim_{x \to \alpha} {f(x)} + \displaystyle\lim_{x \to \alpha} {g(x)}$
5. $\displaystyle\lim_{x \to \alpha} {f(x) \cdot g(x)} = \displaystyle\lim_{x \to \alpha} {f(x)} \cdot \displaystyle\lim_{x \to \alpha} {g(x)}$
6. $\forall x \in E  \ \ \displaystyle\lim_{x \to \alpha} {f(x)} \neq 0 \Rightarrow \displaystyle\lim_{x \to \alpha} {\dfrac{1}{f(x)}} = \dfrac{1}{\displaystyle\lim_{x \to \alpha} {f(x)}}$
7. $\displaystyle\lim_{x \to \alpha} {\dfrac{g(x)}{f(x)}} = \dfrac{\displaystyle\lim_{x \to \alpha} {g(x)}}{\displaystyle\lim_{x \to \alpha} {f(x)}}$
8. $\forall x \in E \ \ f(x) < g(x) \Rightarrow \displaystyle\lim_{x \to \alpha} {f(x)} < \displaystyle\lim_{x \to \alpha} {g(x)}$
9. $\displaystyle\lim_{x \to \alpha} {f(x)} = A, \displaystyle\lim_{x \to \alpha} {h(x)} = A, \ \ \ f(x) \leq g(x) \leq h(x) \Rightarrow \displaystyle\lim_{x \to \alpha} {g(x)} = A$
