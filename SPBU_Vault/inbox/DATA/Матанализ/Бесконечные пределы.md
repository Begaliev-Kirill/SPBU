# Бесконечные пределы
Введем символы $-\infty, +\infty$ со следующими свойствами:\
$\forall x \in \R$:
1. $x < +\infty,\  x > -\infty, \ -\infty < +\infty$
2. $x + (+\infty) = +\infty, \ x + (-\infty) = -\infty$
3. $c \cdot (+\infty) = +\infty, \ c \cdot (-\infty) = -\infty$
4. $(-1) \cdot (+\infty) = -\infty, \ (-1) \cdot (-\infty) = +\infty$

### Последовательности, стремящиеся к бесконечностям
$\gimel \{a_n\}_{n=1}^{\infty}, a_n \rightarrow +\infty \text{ или } \lim_{n \to \infty} a_n = +\infty \Leftrightarrow \forall M \in \R \ \exists \ N \in \N : \forall n \in \N, n > N \ a_n > M$\
$\gimel \{b_n\}_{n=1}^{\infty}, b_n \rightarrow -\infty \text{ или } \lim_{n \to \infty} b_n = -\infty \Leftrightarrow \forall L \in \R \ \exists \ N_1 \in \N : \forall n \in \N, n > N_1 \ b_n < L$

#### На языке окрестностей
$\omega(+\infty) = (M, +\infty) \Rightarrow a_n > M \Leftrightarrow a_n \in \omega(+\infty)$\
$\omega(-\infty) = (-\infty, L) \Rightarrow b_n < L \Leftrightarrow b_n \in \omega(-\infty)$

$\gimel \ \overline{\R} = \R \cup \{+\infty\} \cup \{-\infty\}, \alpha \in \overline{\R}$\
$\{c_n\}_{n=1}^{\infty}$ - последовательность, $c_n \rightarrow \alpha \Leftrightarrow \forall \omega(\alpha) \ \exists \ N \in \N : \forall n \in \N, n > N \ c_n \in \omega(\alpha)$

### Бесконечно большой и бесконечно малый пределы
$\displaystyle\lim_{n \to \infty} {a_n} = +\infty \Leftrightarrow a_n$ - бесконечно большая последовательность\
$\displaystyle\lim_{n \to \infty} {b_n} = 0 \Leftrightarrow |b_n|_{n \to \infty} \rightarrow 0\Leftrightarrow b_n$ - бесконечно малая последовательность\

Небольшое свойство:\
$\gimel a_n$ - бесконечно большая, $\forall n \in \N \ a_n \neq 0 \Rightarrow \{\frac{1}{a_n}\} \rightarrow 0$ (бесконечно малая)\
Доказательство:\
$\gimel \ \forall \varepsilon > 0 \ M = \frac{1}{\varepsilon}$\
$\forall \varepsilon > 0 \ \exists \ N \in \N : \ \forall n \in \N, n > N \ \ |a_n| > M = \frac{1}{\varepsilon} \Rightarrow |\frac{1}{a_n}| < \varepsilon \Rightarrow \{\frac{1}{a_n}\}_{n \to \infty}^{n = 1}  \rightarrow 0 \ \ \blacksquare$
