# Критерий Коши
## Сам критерий
$\gimel \ \{a_n\}_{n=1}^{\infty}$ - последовательность\
$\forall \epsilon > 0 \ \exists \ N \in \N : \forall n,m \in \N, \ n,m > N\ \ |a_m - a_n| < \epsilon \Leftrightarrow \exists \ \lim_{n \to \infty} a_n = c \in \R$\
Доказать надо будет в обе стороны, то есть необходимость $(\Leftarrow)$ и достаточность $(\Rightarrow)$

### Необходимость ($\Leftarrow$)
$\gimel \ \exists \ \lim_{n \to \infty} a_n = c \in \R$\
$\forall \epsilon > 0 \ \exists \ N \in \N : \forall n \in \N, n > N \ |a_n - c| < \frac{\epsilon}{2}$\
$|a_m - c| < \frac{\epsilon}{2}, |a_n - c| < \frac{\epsilon}{2}$ (верно т.к. $m,n$ берут $> N$)\
$|a_m - a_n| = |(a_m - c) - (a_n - c)| \leq |a_m - c| + |a_n - c| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon \ \blacksquare$

### Достаточность ($\Rightarrow$)
Большое и громоздкое доказательство, можно разделить его на 4 этапа (на экзамене лучше таким не заниматься, а писать все разом):
1. $a_n$ ограничена
2. Находим последовательности супремумов и инфинумов
3. Доказываем что их пределы равны
4. $a_n$ стремится к пределу этих последовательностей (теорема о двух миллиционерах)

$\gimel \{a\}_{n=1}^{\infty}$ - последовательность, $\forall \epsilon > 0 \ \exists N \in \N : \forall n,m \in \N, n,m > N \ |a_m - a_n| < \epsilon$

#### $a_n$ ограничена
$\gimel \epsilon = 1, \exists \ N_0 \in \N : \forall n \in \N, n > N_0 + 1 \ \ |a_n - a_{N_0 + 1}| < 1 \Rightarrow a_{N_0 + 1} - 1 < a_n < a_{N_0+1}+1$\
Возьмём $a_+ = max(a_k), a_- = min(a_k), \ 1 \leq k \leq N_0$\
И зададим границы $a_n$ через $A_+ = max(a_+, a_{N_0 + 1} + 1),\  A_- = min(a_-, a_{N_0 + 1} - 1)$\
Из задания $A_+, A_-$ очевидно, что $\forall n \in \N \ A_- \leq a_n \leq A_+ \Rightarrow a_n$ - ограничена

#### Последовательности супремумов и инфинумов
$\gimel \ E_n = \{x \in \R : \exists k \geq n : x = a_k\}$ - последовательность значений пос-ти с номера $n$\
Очевидно, что $E_{n+1} \subset E_n \subset \dots \subset E_1$

$\gimel E, F$ - ограниченные множества, тогда\
$E \subset F \Rightarrow \sup E \leq \sup F, \inf E \geq \inf F$\
$\forall x \in E \ x \leq \sup E \Rightarrow x \leq \sup F, \ x \geq \inf E \Rightarrow x \geq \inf F$\
$\forall x \in E \ \inf F \leq \inf E \leq x \leq \sup E \leq \sup F \Rightarrow \inf F \leq \sup E$

$\gimel \ \begin{rcases} b_n = \sup E_n \\ c_n = \inf E_n \end{rcases} \Rightarrow$ т.к. $\inf E \leq x \leq \sup E$, то $c_n \leq b_n$

$\forall n \in \N \ a_n \leq A_+ \Rightarrow \sup E \leq A_+$ ($b_n$ ограничена сверху)\
$\forall n \in \N \ a_n \geq A_- \Rightarrow \inf E \geq A_-$  ($c_n$ ограничена снизу)

$E_{n+1} \subset E_n \Rightarrow \begin{cases} \forall n \in \N b_{n+1} \leq b_n \text{(последовательность } b_n \text{ убывающая)} \\ \forall n \in \N c_{n+1} \geq c_n \text{(последовательность } c_n \text{ возрастающая)} \\ \end{cases}$

$b_1 = \sup E_1 \geq A_-$ (последовательность $b_n$ ограничена снизу)\
$c_1 = \inf E_1 \leq A_+$ (последоваельность $c_n$ ограничена сверху)

Т.к. $b_n$ убывает и ограничена, то $\exists \lim_{n \to \infty} b_n = b_*$\
Т.к. $c_n$ возрастает и ограничена, то $\exists \lim_{n \to \infty} c_n = c_*$\
Т.к. $\forall n \in \N \ c_n \leq b_n$, то $\lim_{n \to \infty} c_n \leq \lim_{n \to \infty} b_n \Rightarrow c_* \leq b_*$

#### Докажем, что $c_* = b_*$ (от противного)
$\gimel \ c_* \neq b_* \Rightarrow c_* < b_*$, тогда $b_* - c_* = 2 \epsilon > 0$\
$\gimel \ N \in \N$ такое, что $\forall m,n > N \ |a_m - a_n| < \frac{\epsilon}{2} \Rightarrow \forall n > N+1 |a_n - a_{N+1}| < \frac{\epsilon}{2} \Leftrightarrow$\
$\Leftrightarrow a_{N+1} - \frac{\epsilon}{2} < a_n < a_{N+1} + \frac{\epsilon}{2}$\
$b_{N+2} \leq a_{N+1} + \frac{\epsilon}{2},\ \  b_{N+2} \geq b_*$\
$c_{N+2} \geq a_{N+1} - \frac{\epsilon}{2}, \ \ c_{N+2} \leq c_*$\
Совместив два правых неравенства получим $b_{N+2} - c_{N+2} \geq b_* - c_* = 2 \epsilon$\
При этом из двух левых неравенств следует $b_{N+2} - c_{N+2} \leq a_{N+1} + \frac{\epsilon}{2} - a_{N+1} + \frac{\epsilon}{2} = \epsilon$\
$2 \epsilon \leq b_{N+2} - c_{N+2} \leq \epsilon$ - противоречие $\Rightarrow c_* = b_*$

#### Докажем, что $a_n \rightarrow a = c_* = b_*$
По сути это доказательство теоремы о двух миллиционерах, не знаю почему не использовали уже доказанное свойство.

$\forall \epsilon > 0 \begin{cases} \exists \ N_1 \in \N : \forall n \in \N, n > N_1 \ |b_n - b_*| < \frac{\epsilon}{2} \\ \exists \ N_2 \in \N : \forall n \in \N, n > N_2 \ |c_n - c_*| < \frac{\epsilon}{2} \end{cases}$

$\begin{rcases} b_* \leq b_n < b_* + \frac{\epsilon}{2} \\ c_* \geq c_n > c_* + \frac{\epsilon}{2}\end{rcases}$ при $N > N_1, N_2$\
$\gimel N = max(N_1, N_2)$\
т.к. $c_n \leq a_n \leq b_n$, то $a - \frac{\epsilon}{2} \leq c_n \leq a_n \leq b_n \leq a + \frac{\epsilon}{2} \Rightarrow a - \frac{\epsilon}{2} \leq a_n \leq a + \frac{\epsilon}{2} \Rightarrow a_n \rightarrow a \ \ \blacksquare$
