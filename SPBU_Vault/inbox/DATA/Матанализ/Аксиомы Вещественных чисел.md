# Аксиомы Вещественных чисел
$(F, +, \cdot)$ - поле вещественных чисел. Аксиомы поля были затронуты на лекции поверхностно:

1. $a + b = b + a$ - коммутативность сложения
2. $a + (b + c) = (a + b) + c$ - ассоциативность сложеня
3. $\exists \ 0 : \forall x \in F : x + 0 = x$ - существование нейтрального по сложению элемента (нуля)
4. $\forall x \in F \ \exists! \ y \in F : y = -x$ - существование противоположного элемента
5. $a \cdot b = b \cdot a$ - коммутативность умножения
6. $(a \cdot b) \cdot c = a \cdot (b \cdot c)$ - ассоциативность умножения
7. $\exists \ 1 : \forall x \in F : x \cdot 1 = x$ - существование нейтрального по умножению элемента (единицы)
8. $\forall x \in F, x \neq 0 \ \exists ! \ y \in F : y = \frac{1}{x}$ - существование обратного элемента
9. $a \cdot (b + c) = ab + ac$ - связь сложения и умножения
10. Аксиома Архимеда: $\forall x, y \in \R, x,y > 0 \ \exists \ n \in \N : n\cdot x > y$
11. Аксиома о существовании супремума:

     Пусть $E \subset \R, E \neq \emptyset$, $E$ ограничено сверху $<=> \forall x \in E \ \exists c \in \R : x \leq c$, тогда с - верхняя граница $E$. Если $E$ ограничено сверху, то $\exists \ c_0 : \forall x \in E : x \leq c_0$, если при этом $\forall c \in \R , c \ - \text{верхняя граница } E : c_0 \leq c, \text{ то } c_0 - \sup E$ (супремум, минимальная верхняя граница)
