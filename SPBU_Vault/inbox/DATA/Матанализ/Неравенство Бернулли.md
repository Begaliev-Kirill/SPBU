# Неравенство Бернулли
$\gimel x \in \R, x > -1, x \neq 0, n \in \N, n \geq 2$, тогда\
$(1+x)^n > 1 + xn$

Доказательство (по мат индукции):\
База $n = 2$: $(1+x)^2 = 1 + 2x + x^2 > 1 + 2x$ - верно т.к. $x^2 > 0$\
Индукционный переход: $\gimel$ для $n \in \N$ неравенство верно, докажем $n \Rightarrow n+1$\
$(1+x)^{n+1} = (1+x)(1+x)^n > (1 + x)\cdot(1 + nx)$ по индукционном предположению $\Rightarrow$\
$\Rightarrow 1 + nx + x + nx^2 = 1 + (n+1)x + nx^2 > 1 + (n+1)x$ т.к. $nx^2 > 0 \ \ \blacksquare$
