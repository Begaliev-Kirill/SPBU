# Последовательности
### Определение и обозначения
$(f, \N, \R)$ - последовательность(тройка из отображения, натуральных и вещественных чисел), часто записывают как $\{x_n\}^{\infty}_{n=1}$
$\forall n \in \N \ f(n) \in \R, x_n = f(n)$ 
$\gimel x \in \R, \forall \epsilon > 0 \ U(x), V(x), \omega(x)$ - обозначения окрестности $(x-\epsilon, x+\epsilon)$

### Предел последовательности
$\gimel \{x_n\}^{\infty}_{n=1}, a \in \R$
$\lim_{n \to \infty} = a \Leftrightarrow \forall \epsilon > 0 \ \exists \ N : \forall n > N \ |x_n - a| < \epsilon \ \Leftrightarrow \forall \ V(a) \ \exists \ N : \forall n > N x_n \in V(a)$
В таком случае а называют пределом последовательности, и говорят что последовательность *стремится* к а при n стремящемся к бесконечности

## Свойства пределов последовательности
### Единственность предела
Утверждение: \
$x_n \rightarrow_{n \rightarrow \infty} a$  и $x_n \rightarrow_{n \rightarrow \infty} b \Rightarrow a=b$

Доказательство: \
$\gimel x_n \rightarrow a, x_n \rightarrow b, a \neq b$ \
$b \neq a \Leftrightarrow |b-a| > 0, \text{Пусть} \ d = |b-a|$ \
$\gimel \epsilon = \frac{d}{4} > 0$ \
$x_n \rightarrow a \Rightarrow \exists \ N_1 : \forall n > N_1 \ |x_n -a| < \epsilon$ \
$x_n \rightarrow b \Rightarrow \exists \ N_2 : \forall n > N_2 \ |x_n-b| < \epsilon$ \
$\gimel n = N_1 + N_2 + 1$ (просто фиксируем порядковый номер который точно будет удовлетворять под оба условия) \
Из двух неравенств выше следует, что\
$|b-a| = |(b-x_n) + (x_n -a)| \leq |b - x_n| + |x_n - a| < \frac{d}{4} + \frac{d}{4} = \frac{d}{2}$ \
Получается $|b-a| = d < \frac{d}{2}$ - противоречие, значит a = b $\blacksquare$ 

### Ограниченность сходящейся последовательности
$\gimel E = \{x : \exists \ n \in \N : x = x_n\}$ - множество значений последовательности $x_n$\
$E$ - ограничен $\Leftrightarrow \exists \ A,B : \forall x \in E \ A \leq x \leq B \Leftrightarrow  \exists \ L : \forall x \in E \ |x| \leq L$\
Во втором случае с модулем мы ограничиваем через $[-L, L]$

Утверждение: $x_n \rightarrow a \Rightarrow \{x_n\}_{n=1}^{\infty} \ ограничена, a \in \R$ (использую $x \rightarrow a$ вместо $x \underset{n \rightarrow \infty}{\rightarrow} a$ )\
Доказательство:
$\forall \epsilon > 0 \ \exists \ N_0 : \forall n > N_0 \ |x_n - a| < \epsilon \Leftrightarrow a - \epsilon < x_n < a + \epsilon$ при $n > N_0$\
$\gimel M_1 : |x_k| \leq M_1, 1 \leq k \leq N_0$

$\gimel M = max(M_1, |a+\epsilon|, |a-\epsilon|)$\
Рассмотрим два случая:
1. $n > N_0 \Rightarrow |x_n| \leq max(|a+\epsilon|, |a-\epsilon|) \leq M$
2. $1 \leq n \leq N_0 \Rightarrow |x_n| \underset{\text{по созданию } M_1}{\leq} M_1 \leq M$`

Из случаев 1, 2 $\Rightarrow \forall n \in \N \ |x_n| \leq M \Rightarrow$ $\{x_n\}_{n = 1}^{\infty}$ ограничена $\blacksquare$
### Предел последовательности из константы
$\gimel x_n = a \ \forall n \in \N \Rightarrow \lim_{n \to \infty}x_n = \lim_{n \to \infty}a = a$\
Микродоказательство: $\gimel N = 1, \forall \epsilon > 0$ при $N = 1 \ \forall n > 1 \ \ |x_n-a| = |a-a| = 0 < \epsilon \ \blacksquare$
### Предел с умножением на константу
Утверждение: $\gimel \{x_n\}_{n=1}^{\infty}, c \in \R, x_n \rightarrow a, a \in \R \Rightarrow cx_n \rightarrow ca$\
Доказательство:\
Рассмотрим два случая:
1. $\gimel c = 0 \Rightarrow 0 \cdot x_n = 0, 0 \cdot a = 0 \Rightarrow 0 \rightarrow 0$
2. $\gimel c \neq 0$\
$\forall \epsilon > 0 \ \exists \ N : \forall n > N \ \ |x_n-a| < \frac{\epsilon}{|c|}$\
Тогда $|cx_n - ca| = |c| \cdot |x_n - a| < |c| \cdot \frac{\epsilon}{|c|} = \epsilon \Rightarrow cx_n \rightarrow ca \ \blacksquare$
### Константа не влияет на эпсилон
$\gimel \{x_n\}_{n=1}^{\infty}$\
Утверждение:\
Если $\exists \ M > 0$ не зависящее от n $:\forall \epsilon > 0 \ \exists \ N : \forall n > N \ \ |x_n - a| < M\cdot\epsilon$, то $x_n \rightarrow a$\
Доказательство:\
$\gimel \ \forall \epsilon > 0 \ \exists \ \epsilon_1 :  \epsilon_1 = M \cdot \epsilon \Rightarrow \epsilon = \frac{\epsilon_1}{M}$\
Тогда $\forall \epsilon > 0 \ \exists N : \forall n > N \ \ |x_n - a| < M \cdot \epsilon = \epsilon_1 > 0 \Rightarrow x_n \rightarrow a \ \blacksquare$\
Свойство означает, что если мы получили неравенство с каким-нибудь $\epsilon \cdot M$, то предел последовательности от этого не меняется и константу можно смело отбросить.

### Предел суммы последовательностей равен сумме их пределов 
Утверждение: $\gimel x_n \rightarrow a, y_n \rightarrow b \Rightarrow x_n + y_n \rightarrow a + b$\
Доказательство:\
$\forall \epsilon > 0$:
1. $\exists N_1 : \forall n > N_1 \ \ |x_n - a| < \epsilon$
2. $\exists N_2 : \forall n > N_2 \ \ |y_n - b| < \epsilon$

$\gimel N = max(N_1, N_2) \Rightarrow \forall n > N$ выполняются оба утверждения выше $\Rightarrow$\
$\Rightarrow |x_n + y_n - (a+b)| = |(x_n - a) + (y_n - b)| \leq |x_n  - a| + |y_n - a| < \epsilon + \epsilon = 2 \epsilon \Rightarrow x_n + y_n \rightarrow a + b \ \blacksquare$
### Предел произведения последовательностей равен произведению их пределов
Утверждение: $\gimel x_n \rightarrow a, y_n \rightarrow b \Rightarrow x_n y_n \rightarrow ab$\
Доказательство:\
Т.к. $y_n \rightarrow b$, то $y_n$ ограничено $\Rightarrow \exists \ M > 0$ (не зависящее от $n$) $: \forall n \in \N \ \ |y_n| < M$
$\forall \epsilon > 0$:
1. $\exists N_1 : \forall n > N_1 \ \ |x_n - a| < \epsilon$
2. $\exists N_2 : \forall n > N_2 \ \ |y_n - b| < \epsilon$

$\gimel N = max(N_1, N_2) \Rightarrow \forall n > N$ выполняются оба утверждения выше\
$x_n y_n - ab  = (x_n - a)y_n + a(y_n - b) \Rightarrow |x_n y_n - ab| \leq |x_n -a||y| + |a||y_n -b| <$\
$< |x_n - a|M + |a||y_n - b|$ (так как $|y_n| < M \ \forall n \in \N$) $< \epsilon M + |a| \epsilon = (M + |a|) \epsilon$\
$M + |a|$ можем отбросить как константу $\Rightarrow x_n y_n \rightarrow ab \ \blacksquare$

### Предел обраной последовательности равен обратному пределу этой последовательности
Утверждение: $\gimel \ \forall n \in \N\  x_n \neq 0, x_n \rightarrow a, a \neq 0$, тогда $\frac{1}{x_n} = \frac{1}{a}$\
Доказательство:\
$\forall \epsilon > 0 \ \exists N_1 : \forall n > N_1 \ \ |x_n - a| < \epsilon$\
$\gimel \epsilon = \frac{|a|}{2} \Rightarrow \exists N_2 : \forall n > N_2 \ \ |x_n - a| < \frac{|a|}{2}$\
$|x_n| = |(x_n - a) + a| \geq |a| - |x_n - a| > |a| - \frac{|a|}{2} = \frac{|a|}{2}$ ($\forall n \in \N, n > N_2$)\
$|x_n| > \frac{|a|}{2} \Rightarrow \frac{1}{|x_n|} < \frac{2}{|a|}$\
$\gimel N = max(N_1, N_2)$, тогда $\forall n \in \N, n > N \ \ |x_n - a| < \epsilon$ и $\frac{1}{|x_n|} < \frac{2}{|a|}$\
$|\frac{1}{x_n} - \frac{1}{a}| = |\frac{a - x_n}{x_n a}| = \frac{1}{|a|} \cdot \frac{1}{|x_n|} \cdot |x_n - a| \leq \frac{1}{|a|} \cdot \frac{2}{|a|} \cdot \epsilon = \frac{2}{a^2} \epsilon$\
$\frac{2}{a^2}$ отбрасываем как константу $\Rightarrow \frac{1}{x_n} \rightarrow \frac{1}{a} \ \blacksquare$

### Предел частного последовательностей равен частному их пределов
Свойство вытекает из предыдущих двух
$\gimel \ \forall n \in \N \  x_n \neq 0, x_n \rightarrow a, a \neq 0, y_n \rightarrow b$, тогда $\frac{y_n}{x_n} \rightarrow \frac{b}{a}$\
Доказательство: $\frac{y_n}{x_n} = y_n \cdot \frac{1}{x_n} \rightarrow b \cdot \frac{1}{a} = \frac{b}{a} \ \blacksquare$

### Предельный переход в неравенствах
Утверждение: $\gimel x_n \rightarrow a, y_n \rightarrow b, \forall n \in \N \ x_n \leq y_n \Rightarrow a \leq b$\
Доказательство(от противного):\
$\gimel a > b, \epsilon  = \frac{a-b}{4}$\
$\exists N_1 : \forall n \in \N > N_1 \ \ a - \frac{a-b}{4} < x_n < a + \frac{a-b}{4}$\
$\exists N_2 : \forall n \in \N > N_2 \ \ b - \frac{a-b}{4} < y_n < b + \frac{a-b}{4}$\
$\gimel n_0 = 1 + N_1 + N_2$ (чтобы подошел под оба неравенства)\
$x_{n_0} > a - \frac{a-b}{4} = \frac{3a+b}{4}$\
$y_{n_0} < b + \frac{a-b}{4} = \frac{3b+a}{4}$\
Т.к. $a > b$, то $\frac{3a+b}{4} > \frac{3b+a}{4}$\
Получаем $\frac{3a+b}{4} < x_{n_0} \leq y_{n_0} < \frac{3b + a}{4}$, но $\frac{3a+b}{4} > \frac{3b+a}{4}$ - противоречие $\Rightarrow a \leq b \ \blacksquare$

Так же можно доказать, что $x_n < y_n \Rightarrow a \leq b$
### Теорема о двух миллиционерах (она реально так называется)
Утверждение: $\gimel x_n, y_n, z_n, \ x_n \leq y_n \leq z_n, \ x_n \rightarrow a, z_n \rightarrow a \Rightarrow y_n \rightarrow a$\
Доказательство:\
$\forall \epsilon > 0$:
1. $\exists N_1 : \forall n > N_1 \ \ |x_n - a| < \epsilon \Rightarrow a - \epsilon < x_n < a + \epsilon$
2. $\exists N_2 : \forall n > N_2 \ \ |z_n - a| < \epsilon \Rightarrow a - \epsilon < z_n < a + \epsilon$

$\gimel N = max(N_1, N_2)$\
Тогда $\forall \epsilon > 0 \ \forall n \in \N, n > N \ \ a - \epsilon < x_n \leq y \leq z_n < a + \epsilon \Rightarrow$ $\Rightarrow a - \epsilon < y_n < a + \epsilon \Rightarrow y_n \rightarrow a \ \blacksquare$

### Теорема о пределе монотонно возрастающей последовательности
$\{x_n\}_{n=1}^{\infty}$ монотонно возрастает(строго возрастает) $\Leftrightarrow \forall n \in \N \ x_n \leq (<) x_{n+1}$ \
$\{x_n\}_{n=1}^{\infty}$ монотонно убывает(строго убывает) $\Leftrightarrow \forall n \in \N \ x_n \geq (>) x_{n+1}$

Утверждение: $\gimel \{x_n\}^{\infty}_{n=1}$ монотонно возрастает $(x_n \leq x_{n+1})$ и $\exists \ M : \forall n \in \N \ x_n \leq  M$, тогда:
1. $\exists \lim_{n \to \infty} x_n = a$ (1)
2. $a \leq M, \forall n \in \N \  x_n \leq a$ (2)

Доказательство:\
$\gimel E = \{x : \exists n \in \N : x_n = x\}, E \neq \varnothing$\
т.к. $\forall n \in \N \ x_n \leq M$, то $E$ - ограничено сверху $\Rightarrow \exists \sup{E} = a \Rightarrow \forall n \in \N \ x_n \leq a \leq M$\
Если докажем, что $a - предел$, то выполнение пункта (2) будет следовать из нер-ва выше\
$\forall \epsilon > 0 \ a - \epsilon < a \Rightarrow a - \epsilon$ - не верхняя граница множества $E \Rightarrow \exists x_N \in E : x_N > a-\epsilon$\
$\forall n \in \N, n > N \ \ a - \epsilon < x_N \leq x_{N+1} \leq \dots \leq x_{n-1} \leq x_{n} \leq a \Rightarrow$\
$\Rightarrow a - \epsilon < x_n \leq a < a + \epsilon \Rightarrow x_n \rightarrow a \ \ \blacksquare$
### Теорема о пределе монотонно убывающей последовательности
Утверждение: $\gimel \{y_n\}_{n=1}^{\infty}$ монотонно убывает ($y_n \geq y_{n+1}$) и $\exists L : \forall n \in \N \ y_n \geq L$, тогда:
1. $\exists \lim_{n \to \infty} y_n = b$
2. $b \geq L,\forall n \in \N \ y_n \geq b$

Доказательство:\
$\gimel E = \{y : \exists n \in \N : y_n = y\}$\
т.к. $\forall n \in \N \ y_n \geq L$, то $E$ - ограничено снизу $\Rightarrow \exists \ \inf{E} = b \Rightarrow \forall n \in \N \ y_n \geq b \geq L$\
Как и в прошлый раз, осталось доказать что b - предел\
$\gimel x_n = -y_n \Rightarrow \forall n \in \N \ x_n \leq -L$\
$\gimel M = -L$\
$y_n \geq y_{n+1} \Rightarrow x_{n} \leq x_{n+1}$\
По прошлой теореме о пределе монотонно возрастающей последовательности мы получаем, что $x_n \rightarrow a$\
$x_n \rightarrow a \Rightarrow y_n = -x_n \rightarrow -a = b \ \ \blacksquare$
