# Теорема Кантора о сходящихся вложенных промежутках
$\gimel \{a_n\}^{\infty}_{n=1}, \{b_n\}^{\infty}_{n=1}$ - последовательности, $\forall n \in \N \ \ a_n \leq a_{n+1} \leq \dots \leq b_{n + 1} \leq b_n$\
Тогда мы имеем набор вложенных промежутков $[a_{n+1}, b_{n+1}] \subset [a_n, b_n]$

## Теорема Кантора
Утверждение: $\gimel \{a_n\}^{\infty}_{n=1}, \{b_n\}^{\infty}_{n=1}$ - набор вложенных промежутков $[a_n, b_n]$\
Тогда $b_n - a_n \rightarrow_{n \rightarrow \infty} 0 \Leftrightarrow \exists ! \ c \in \R : \forall n \in \N \ c \in [a_n, b_n]$

Доказательство: Нужно доказать и существование $(\exists)$, и единственность $(!)$\
$(\exists) \ a_1 \leq a_2 \leq \dots \leq a_n < b_n \leq \dots \leq b_2 \leq b_1 \Rightarrow$\
$\Rightarrow a_1 \leq a_n < b_n \leq b_1 \Rightarrow \forall n \in \N \ b_n > a_1 \ , \ a_n < b_1 \Rightarrow b_n \geq b_{n+1} > a_1 \ , \ a_n \leq a_{n+1} < b_1$\
Тогда получаем, что $\{b_n\}$ - монотонно убывающая последовательность и ограничена снизу, тогда $\exists \lim_{n \to \infty} b_n = b_*, b_* \geq a_1$\
При этом $\{a_n\}$ - монотонно возрастающая последовательность и ограничена снизу, тогда\
$\exists \lim_{n \to \infty} a_n = a_*, a_* \leq b_1$\
Так как $\forall n \in \N \ a_n < b_n$, то $\lim_{n \to \infty} a_n \leq \lim_{n \to \infty}b_n \Rightarrow a_* \leq b_*$

Докажем, что $a_* = b_*$ (от противного)\
$\gimel a_* \neq b_* \Rightarrow a_* < b_*$\
$\forall n \in \N \ b_n \geq b_* \ , \ a_n \leq a_*$, совместив два неравенства получим $b_n - a_n \geq b_* - a_* \Rightarrow$\
$\Rightarrow \lim_{n \to \infty} (b_n - a_n) \geq \lim_{n \to \infty} (b_* - a_*) \Rightarrow 0 \geq b_* - a_*$, но $a_* < b_*$ по предположению $\Rightarrow$\
$\Rightarrow$ $b_* - a_* > 0$ - получили противоречие\
Учиывая $a_* \leq b_*$ (1) и $0 \geq b_* - a_*$, получаем $a_* = b_*$, обозначим $a_* = b_* = c$\
$\begin{rcases} \forall n \in \N  \ c = a_* \geq a_n \\ \forall n \in \N \ c = b_* \leq b_n  \end{rcases}$ $\Rightarrow \forall n \in \N \ c \in [a_n, b_n]$

$(!)$ Докажем единственность такой точки (от противного)\
$\gimel \ \exists \ c_1 \neq c : \forall n \in \N \ c_1 \in [a_n, b_n]$\
Возьмем $c_1 < c$, неравенство ни на что не влияет т.к. доказывается равенство точек\
$\forall n \in \N c, c_1 \in [a_n, b_n] \Rightarrow a_n \leq c_1 < c \leq b_n \Rightarrow b_n - a_n \geq c - c_1 \Rightarrow \lim_{n \to \infty} (b_n - a_n) \geq \lim_{n \to \infty} (c - c_1) \Rightarrow$\
$\Rightarrow 0 \geq c - c_1$, но $c_1 < c \Rightarrow c - c_1 > 0 \Rightarrow$ противоречие $\Rightarrow c_1 = c \ \blacksquare$
