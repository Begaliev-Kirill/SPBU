### Конспекты
Все готовые PDF лежат в папке **Release.** \
При желании вы можете скопировать все записи в сыром .md формате из директории SPBU_Vault, все формулы записаны с помощью библиотеки **KaTeX** (быстрое ответвление от LaTeX), лично я для конспектирования использую ZenNotes.

### Редактирование и дополнение
При желании вы можете дополнить репозиторий своими материалами/записями/правками через Pull Request, главное правило - сохранять понятную структуру репозитория и, при необходимости, дополнять содержимое с помощью README.md
